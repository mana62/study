# 動的インポート
👉 **必要になった瞬間にだけモジュールを読み込む仕組み**

## 書き方
```js
const module = await import("./path/to/module.js");
```
- import() は 関数のように使う
- Promise を返すので await が使える
- 読み込みは その瞬間に行われる

## 動的インポートの核心
- import() を 関数のように使って、あとからモジュールを読み込む
- 読み込みは 非同期（Promise）
- 必要なときだけ読み込むので 初期表示が速くなる
- 条件分岐の中でも使える

例：
```js
button.addEventListener("click", async () => {
  const module = await import("./utils.js");
  module.runSomething();
});
```

## 静的インポートとの違い
**静的インポート（普通の import）**
```js
import { foo } from "./utils.js";
```
- ファイル読み込み時に必ず実行される
- 条件分岐の中では使えない
- 初期ロードが重くなることもある

**動的インポート**
```js
const module = await import("./utils.js");
```
- 必要になった瞬間に読み込む
- 条件分岐の中で使える
- 初期ロードを軽くできる

| 種類            | 書き方                     | 読み込まれるタイミング | 使える場所                |
| --------------- | -------------------------- | ---------------------- | ------------------------- |
| 静的インポート  | import x from "./a.js"     | ファイル読み込み時     | ファイル先頭のみ          |
| 動的インポート  | await import("./a.js")     | 実行した瞬間           | どこでもOK（if, click, async） |


## どんなときに使えるのか
- 関数の中
  - 必要なときだけ読み込めるので、初期ロードを軽くできる
- 条件分岐の中（if / switch）
  - 状況に応じて読み込むモジュールを変えられる
- イベントハンドラの中（click / change / scroll など）
  - ユーザー操作が起きた瞬間にだけ読み込む
- ループの中
  - 動的にパスを変えて読み込むことも可能
- 非同期処理（async/await）の中
  - import() は Promise を返すので await と相性が良い
- 重いライブラリを必要なときだけ読み込みたいとき
  - 例：地図、グラフ、画像編集などの大きいライブラリ
- SSR（サーバーサイドレンダリング）でクライアント専用コードを避けたいとき
  - window や document を使うコードをクライアント側でだけ読み込める
- ユーザーの設定や環境によって読み込むファイルを変えたいとき
  - 例：言語ファイル（ja / en）を動的に切り替える

## 具体例
- ボタンを押したらモーダル用の JS を読み込む
- 管理者だけ admin.js を読み込む
- ユーザーの言語に応じて messages/ja.js や messages/en.js を読み込む
- 重い chart.js をグラフ表示ボタンを押したときだけ読み込む

## ポイント
- 動的インポートは Promise を返す
- await import() と書くと読みやすい
- import map とも併用できる
- Webpack / Vite などのバンドラは動的インポートを使うと自動でコード分割（chunk）してくれる
