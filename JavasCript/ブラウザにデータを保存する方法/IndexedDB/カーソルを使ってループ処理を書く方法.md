# カーソルを使ってループ処理を書く方法（Cursor（カーソル））

## 普通のループだと効率が悪い

例えば
```js
store.getAll()
```
これで `全部のデータ → 配列` にしてから `for(...)` でループできる

しかし問題がある👇
- 全部のデータを一度メモリに入れる
- なのでデータが多いと重い

## そこで Cursor（カーソル）
- IndexedDBでは **Cursor = データを1件ずつ読む仕組み**

イメージ👇
```bash
DB
 ↓
1件取得
 ↓
次へ
 ↓
次へ
 ↓
次へ
```

## Cursorの基本コード
```js
const request = store.openCursor();

request.onsuccess = (event) => {
  const cursor = event.target.result;

  if (cursor) {
    console.log(cursor.key);
    console.log(cursor.value);

    cursor.continue();
  }
};
```
流れ👇
1. データ取得
2. 処理
3. continue()
4. 次のデータ
＝ これを繰り返す

## Cursorの中に入っているもの
- cursorには3つ重要な値がある
```js
cursor.key
cursor.value
cursor.primaryKey
```
意味：
```bash
key        → indexのキー
value      → データ本体
primaryKey → 元のID
```

## continue()
```js
cursor.continue();
```
意味：次のデータへ進む

これを呼ぶと
```bash
successイベント
↓
もう一度実行
```
されるので、**疑似ループ** になっている

## データが終わるとどうなる？
最後までいくと
```js
cursor = null
```
になる

そのため必ず書く👇
```js
if(cursor){
   ...
}
```

## indexでも使える
ObjectStoreだけでなく

```js
index.openCursor()
```
でも使える

違い：
- ObjectStore → ID順
- Index → Indexキー順

## 範囲指定もできる
```js
store.openCursor(range)
```
例： 1〜4だけなど可能

## 並び順も変更できる
第2引数
```js
openCursor(range, direction)
```

種類
```bash
next      小さい順
prev      大きい順
nextunique
prevunique
```

## advance()：()内の数字をスキップ
```js
cursor.advance(2)
```
意味：2件スキップ

例：
```bash
1
3
5
```
みたいに取得できる：()内の数字までジャンプ

## continue(key)
```js
cursor.continue(3)
```
意味：キー3まで一気にジャンプ

ただし **現在のキーより大きい必要**

## まとめ
- IndexedDBでループする方法は **`openCursor()`**

基本コードはこれ👇
```js
store.openCursor().onsuccess = (e) => {
  const cursor = e.target.result;

  if (cursor) {
    console.log(cursor.value);

    cursor.continue();
  }
};
```

流れ：
```bash
1件取得
↓
処理
↓
continue()
↓
次のデータ
```

## 現場では下記のように書かれる
```js
const request = store.openCursor();

request.onsuccess = (e) => {
  const cursor = e.target.result;
  if (!cursor) return;

  console.log(cursor.value);

  cursor.continue();
};
```

- IndexedDBで覚えるべき3つ
  - ① ObjectStore
  - ② Index
  - ③ Cursor

構造
```bash
DB
 ↓
ObjectStore
 ↓
Index
 ↓
Cursor
```
