# キーを変更する方法

## IndexedDBの「キー」とは
👉 データを識別するID

```js
// 例
{id: 1, title: "JavaScript"}
{id: 2, title: "Python"}
```

## autoIncrement（自動ID）
- オブジェクトストア作成時に設定できる

```js
db.createObjectStore("books", {
  autoIncrement: true
});
```
上記のように書くと、**キーを指定しなくても自動で番号が付く**

例:
```js
store.add("JavaScript");
store.add("Python");
store.add("React");
```
結果
```bash
1 → JavaScript
2 → Python
3 → React
```

## 手動でキーを指定することもできる
```js
store.add("JavaScript", 10);
```

## 小さい数字を入れても基準は変わらない
例:
- 現在の最大キー = 5

ここで下記のようにする
```js
store.add("Book", 2);
```
👉 この場合は、**次の自動キーは6になる**

## keyPath（オブジェクトの中のIDをキーにする）
設定:
```js
db.createObjectStore("books", {
  keyPath: "id"
});
```
意味: **オブジェクトの id をキーとして使う**

例:
```js
store.add({id:1, title:"JavaScript"});
store.add({id:2, title:"Python"});
```
＝ ここではidがキーになる

## keyPathを使うとオブジェクトしか保存できない
keyPath設定
```js
keyPath: "id"
```
上記のように設定した場合は、**必ずオブジェクトにする**

```js
store.add({
  id:1,
  title:"JavaScript"
});
```
❌ これはエラー
```js
store.add("JavaScript");
```

## keyPath + autoIncrement
この組み合わせが一番よく使われる
```js
db.createObjectStore("books", {
  keyPath: "id",
  autoIncrement: true
});
```
すると
```js
store.add({title:"JavaScript"});
store.add({title:"Python"});
```
結果
```bash
{ id:1, title:"JavaScript" }
{ id:2, title:"Python" }
```
＝ idが自動で追加される

## まとめ
⚫︎ IndexedDBのキー設定は3種類
| 方法            | 例                    |
| ------------- | -------------------- |
| 手動キー          | `store.add(data, 1)` |
| autoIncrement | 自動ID                 |
| keyPath       | オブジェクトのプロパティをキー      |

一番よく使うのは
```js
keyPath: "id",
autoIncrement: true
```
