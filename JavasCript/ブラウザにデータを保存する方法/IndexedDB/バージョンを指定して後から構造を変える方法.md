# バージョンを指定して後から構造を変える方法

## 問題：DB構造はあとから変えられるのか
- IndexedDBでは
```js
createObjectStore()
createIndex()
```
は `upgradeneeded` の中でしか使えない
つまり普通に考えると **DB作ったあとに構造変更できない**ように見える

## 解決方法：DBにはバージョンがある
- IndexedDBには `version` という概念がある

例：
```js
indexedDB.open("myDB", 1)
```
ここで `1 = バージョン`

## バージョンを上げると upgradeneeded が発生
例：
```js
indexedDB.open("myDB", 2)
```
すると `version 1 → 2` になるので `upgradeneeded` が もう一度発生
つまり **DB構造変更できる**

## そこで構造変更を書く
```js
const request = indexedDB.open("myDB", 2);

request.onupgradeneeded = (e) => {
  const db = e.target.result;

  db.createObjectStore("games");
};
```

つまり
```js
version上げる
↓
upgradeneeded発生
↓
構造変更
```

## versionのルール
覚えるのはこれだけ

| ルール           | 説明        |
| ------------- | --------- |
| 0は使えない        | エラー       |
| 整数のみ          | 小数は切り捨て   |
| 小さいバージョンに戻せない | ダウングレード不可 |


例：
```js
open("db", 5)
```

## よくあるエラー
例えば：
```js
db.createObjectStore("books");
```
を毎回実行すると既に存在するエラーになる

## そこで oldVersion を使う
- upgradeneeded のイベントには

```js
oldVersion
newVersion
```
がある

例：
```js
request.onupgradeneeded = (e) => {
  const db = e.target.result;

  if (e.oldVersion < 1) {
    db.createObjectStore("books");
  }

  if (e.oldVersion < 2) {
    db.createObjectStore("games");
  }
};
```

これで **安全にバージョンアップできる**

## 複数タブ問題
IndexedDBは **同じOriginで共有**
つまり
- タブA
- タブB
両方で同じDBを使っている

## タブAがversionアップしたら？
問題：タブBが古い構造のままになる可能性
なのでブラウザは **待機**

## versionchangeイベント
古いタブでは `versionchange` イベントが発生

例：
```js
db.onversionchange = () => {
  db.close();
};
```
これをすると `DBを自動で閉じる` のでアップグレード可能になる

## blockedイベント
- もし古いタブが `close()`しないと
- 新しいタブでは `blocked` イベントが発生
- 意味：他のタブがDB使ってる

## DB.close()
```js
db.close();
```
- するとDB接続終了その後
- transactionなど使えない
- エラーになる

## まとめ
IndexedDBでDB構造変更する流れ

1. DB version上げる
2. upgradeneeded発生
3. createObjectStore
4. createIndex

安全な書き方
```js
request.onupgradeneeded = (e) => {
  const db = e.target.result;

  if (e.oldVersion < 1) {
    db.createObjectStore("books");
  }

  if (e.oldVersion < 2) {
    db.createObjectStore("games");
  }
};
```

## IndexedDBの全体像
```bash
IndexedDB
   │
   ▼
Database
   │
   ▼
Transaction
   │
   ▼
ObjectStore
   │
   ├ add / put / get
   │
   ├ Index（検索）
   │
   └ Cursor（ループ）
```
さらに
```bash
Version
↓
upgradeneeded

で構造変更
```
