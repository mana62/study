# キーの範囲を指定してデータを取得する方法

## get() は「1つだけ」取得

```js
store.get(1)
```
意味：**キー1のデータを1つ取得**

## 複数取得したい場合（getAll）
例：キー1〜4のデータ

```js
store.getAll()
```
を使う

## 範囲指定（IDBKeyRange）
範囲を指定する場合、`IDBKeyRange`というAPIで範囲を指定

例：
```js
const range = IDBKeyRange.bound(1, 4);

store.getAll(range);
```
意味：1以上4以下のデータ

## get() と getAll() の違い
| メソッド     | 結果   |
| -------- | ---- |
| get()    | 1つだけ |
| getAll() | 全部   |

## ⚪︎以上だけ取得（lowerBound()）
```js
IDBKeyRange.lowerBound(1)
```
意味：１以上

例：
```js
store.getAll(IDBKeyRange.lowerBound(1))
```

## ⚪︎以下だけ取得（upperBound()）
```js
IDBKeyRange.upperBound(4)
```
意味：4以下

## キーだけ取得（getAllKeys()）
```js
store.getAllKeys()
```
結果：[1,2,3,4]

## 件数だけ取得（count()）
```js
store.count()
```
結果：データ数

## 範囲削除もできる（IDBKeyRange+範囲設定）
```js
store.delete(IDBKeyRange.lowerBound(10))
```
意味：10以上を削除

## よく使うのは 下記4つ
```js
get()
getAll()
count()
delete()

IDBKeyRange.bound()
IDBKeyRange.lowerBound()
IDBKeyRange.upperBound()
```
