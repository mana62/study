# クラウド基礎
クラウド：**インターネット経由で、サーバーやストレージやデータベースを借りて使う仕組み**

仮想化がクラウドのベースになってる

### クラウド構成要素
**３層**で構成されており、
①アプリケーション
②ミドルウェア/OS
③インフラ

### 5つの基本特性
#### ①オンデマンドセルフサービス
→ 必要な時に自分でサーバー作成できる
#### ②広範なネットワークアクセス
→ インターネット経由でどこからでも使える
#### ③リソースの共有化（Resource Pooling）
→ 多くの利用者で設備を共有して使う
#### ④迅速な拡張性（Rapid Elasticity）
→ 必要に応じてすぐ増減できる
#### ⑤計測サービス（Measured Service）
→ 使った分だけ料金が発生する

### SaaS / PaaS / IaaS
- SaaS = 完成したアプリをそのまま使うサービス
- PaaS = アプリを動かすための環境まで提供されるサービス
- IaaS = インフラだけ提供されるサービス

| 種類 | どこまでクラウドがやる？ | ユーザーがやること | 例 |
|------|---------------------------|----------------------|------|
| IaaS | インフラまで | OS〜アプリ全部 | EC2, Azure VM |
| PaaS | インフラ＋実行環境 | アプリ開発だけ | Heroku, App Service |
| SaaS | 全部 | 使うだけ | Gmail, Slack |


### クラウドの３つの提供携帯
①オンプレミス：**サーバーなど全て自社で持つ・管理する方式**
②プライベート：**クラウドだが自社専用の環境**を使用する方式
③ハイブリッド：**オンプレ＋クラウド**を組み合わせる方式
