# ネットワーキングとコンテンツ配信

# ネットワーク基盤
## VPC
- **AWS 上に作る 仮想ネットワークの基礎**
- **サブネット、ルートテーブル、NAT、セキュリティグループ**などを構成

# DNS / ルーティング
## Route 53
- **DNSサービス**
- ドメイン名 → IP アドレスに変換
- ヘルスチェック、ルーティングポリシー対応

# コンテンツ配信（CDN）
## Amazon CloudFront
- **世界 400+ のエッジロケーション**
- **ユーザーに近い場所から高速配信**
- 99.9% 可用性
- S3 / ALB / API Gateway / Lambda@Edge と連携

# グローバル高速化
## AWS Global Accelerator
- グローバルアプリのパフォーマンスを最大 60% 向上
- Anycast IP を提供
- **世界中の AWS ネットワークを経由して最適ルート**
- ヘルスチェックで自動フェイルオーバー
- ALB / NLB / EC2 / EIP などに対応

# ハイブリッド接続（オンプレ × AWS）
## AWS Direct Connect
- **オンプレと AWS を 専用線で接続**
- 高帯域・低レイテンシ・安定通信
- セキュリティ要件が高い企業向け

## AWS Site-to-Site VPN
- **オンプレと AWS を VPN（IPsec）で接続**
- 低コストで導入が簡単
- Direct Connect のバックアップにも使われる

## AWS Client VPN
- **リモートユーザー（社員）を AWS/VPC に接続**
- OpenVPN 互換
- テレワーク向け

## AWS Storage Gateway
- **オンプレのストレージを AWS に拡張**
- S3 バックエンドで容量無限化

# ネットワーク統合・接続管理
## AWS Transit Gateway
- 複数 VPC / オンプレを ハブ＆スポークで一元接続
- 大規模ネットワーク向け
- ルーティング管理を簡素化

## AWS Cloud WAN
- グローバルネットワークを一元管理
- 大規模企業の WAN をクラウドで構築
- Transit Gateway の上位互換的な位置づけ

## AWS PrivateLink
- **VPC 内から AWSサービスや自社サービスをプライベート接続**
- インターネットを通らない
- セキュリティが重要なシステム向け

# API 管理
## Amazon API Gateway
- **API の統一エントリーポイント**
- **Lambda / EC2 / コンテナ / オンプレ と統合**
- 認証、レート制限、キャッシュ、モニタリング
- サーバーレス API の中心的存在

## まとめ
| サービス | 役割 | 主な用途 |
|----------|------|-----------|
| VPC | 仮想ネットワーク | AWS内のネットワーク基盤 |
| Route 53 | DNS | ドメイン管理、名前解決 |
| CloudFront | CDN | 高速コンテンツ配信 |
| Global Accelerator | グローバル高速化 | Anycast IP、最適ルート |
| Direct Connect | 専用線接続 | オンプレとAWSの高速接続 |
| Site-to-Site VPN | VPN接続 | オンプレとAWSをIPsecで接続 |
| Client VPN | リモートVPN | 社員のリモート接続 |
| Transit Gateway | ネットワーク統合 | 複数VPC/オンプレの一元接続 |
| Cloud WAN | グローバルWAN | 大規模企業ネットワーク管理 |
| PrivateLink | プライベート接続 | AWSサービスをVPC内で利用 |
| API Gateway | API管理 | Lambda/EC2/オンプレのAPI統合 |
