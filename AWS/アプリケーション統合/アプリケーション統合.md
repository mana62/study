# AWS アプリケーション統合
AWS のアプリ統合は大きく 4カテゴリ に整理できる：
1. メッセージング（SNS / SQS / MQ）
2. ストリーミング（Kinesis）
3. 通知・メール（SNS / SES）
4. API管理（API Gateway）
5. CI/CD（Codeシリーズ）

# メッセージング（非同期処理の中心）
## Amazon SNS（Simple Notification Service）
- **プッシュ型の通知サービス**
- プッシュ型通知：**アプリやサービス側からユーザーの端末へ自動的にメッセージを送る**仕組み

### 特徴
- プッシュ通知（サブスクライバーへ即時配信）
- メール / SMS / Lambda / SQS などに配信
- 同時配信（ファンアウト）に強い
- 配信後はメッセージを保持しない

### 向いている用途
- 通知（アラート、イベント通知）
- 複数サービスへ同時配信（ファンアウト）

## Amazon SQS（Simple Queue Service）
- **メッセージキュー（ポーリング型）**
- ポーリング型：**一定間隔でこちらから相手に状態どう？と問い合わせ続ける方式**

### 特徴
- メッセージを最大14日保持
- ワーカーが ポーリング して処理
- 再試行最大3回（デフォルト）
- 並列実行・バッチ処理に強い

### 2種類
1. **Standard**：高スループット
2. **FIFO**：順序保証 + 重複なし

#### 向いている用途
- 非同期処理
- バッチ処理
- ワーカーによる並列処理

## SNS と SQS の違い
| 項目 | SNS | SQS |
|------|------|------|
| 配信方式 | プッシュ型 | ポーリング型 |
| メッセージ保持 | なし | 最大14日 |
| 再試行 | 最大3回 | ワーカー側で制御 |
| 向き | 同時配信 | 非同期処理・バッチ |
| 典型構成 | SNS → SQS（ファンアウト） |

## Amazon MQ
- **RabbitMQ / ActiveMQ のマネージド版**

### 特徴
- **既存のメッセージングシステムをクラウド移行したい企業向け**
- JMS / AMQP などのプロトコル対応

# ストリーミング
## Amazon Kinesis
- **リアルタイムデータ収集・処理・分析のためのサービス群**

### 4つのサービス
1. **Kinesis Data Streams**：リアルタイムストリーム
2. **Kinesis Data Firehose**：S3 / Redshift へ自動取り込み
3. **Kinesis Data Analytics**：SQLでリアルタイム分析
4. **Kinesis Video Streams**：動画ストリーミング

### 向いている用途
- IoTデータ
- アクセスログ
- センサーデータ
- リアルタイム分析

# 通知・メール
## Amazon SES（Simple Email Service）
- **メール送信サービス**

### 特徴
- 大量メール送信
- マーケティング / 通知メール
- DKIM / SPF 対応
- コストが安い

# API 管理
## Amazon API Gateway
- API の統一エントリーポイント

### 特徴
- Lambda / EC2 / コンテナ / オンプレと統合
- 認証（Cognito / IAM）
- レート制限
- キャッシュ
- モニタリング（CloudWatch）

### 向いている用途
- サーバーレスAPI
- マイクロサービスAPI
- 外部公開API

# CI/CD（Codeシリーズ）
## CodeCommit
- **Gitリポジトリ**（GitHubのAWS版）

## CodeBuild
- **ビルド・テストの自動化**

## CodeDeploy
- **EC2 / Lambda / ECS へのデプロイ自動化**

## CodePipeline
- **CI/CDパイプラインの統合管理**
（Commit → Build → Deploy を自動化）

# まとめ
| サービス | 役割 | 主な用途 |
|----------|------|-----------|
| SNS | プッシュ通知 | 同時配信、アラート |
| SQS | メッセージキュー | 非同期処理、バッチ |
| MQ | 既存MQの移行 | JMS/AMQP対応 |
| Kinesis | ストリーミング | リアルタイム分析 |
| SES | メール送信 | 通知・マーケティング |
| API Gateway | API管理 | Lambda/EC2統合 |
| CodeCommit | Git管理 | ソース管理 |
| CodeBuild | ビルド | CI |
| CodeDeploy | デプロイ | CD |
| CodePipeline | CI/CD統合 | 自動パイプライン |
