# ストレージ
- AWS のストレージは大きく **オブジェクト / ブロック / ファイル / アーカイブ / ハイブリッド / 一時ストレージ** に分類される

## Amazon S3
- **オブジェクトストレージ**（AWSの代表ストレージ）

### 特徴
- 無制限に保存可能
- 高耐久（99.999999999%）
- 静的サイト、ログ、画像、動画などに最適
- ストレージクラスでコスト最適化可能

### 主なストレージクラス
- Standard：高頻度アクセス
- Standard-IA / One Zone-IA：低頻度アクセス
- Glacier Instant Retrieval：即時取り出し
- Glacier Flexible Retrieval：数分〜数時間
- Glacier Deep Archive：最安、長期保存向け

## Amazon EBS
- **ブロックストレージ**（EC2専用ディスク）

### 特徴
- EC2 にアタッチして使う
- OS や DB のディスクとして利用
- 単一インスタンス向け
- 高速 I/O（SSD系）も選択可能

## Amazon EFS
- **ファイルストレージ**（NFS共有ストレージ）

### 特徴
- 複数の EC2 から同時アクセス可能
- マルチAZで高可用性
- 自動スケーリング
- Linux ワークロード向け
- NFSv4プロトコル

## Amazon S3 Glacier
- **アーカイブストレージ**（長期保存・低コスト）

### 特徴
- バックアップ、災害対策、ログ保管
- 取り出しに時間がかかる（クラスにより数分〜数時間）
- 最安のストレージ

## Amazon FSx
- **高性能なマネージドファイルストレージ**

### 特徴
- 世界標準のファイルシステムをフルマネージドで提供
- 高性能・低レイテンシ
- **Windows や HPC（高速計算）向け**

### FSx のタイプ
- FSx for Windows File Server：Windowsワークロード
- FSx for Lustre：HPC・機械学習・高速処理
- FSx for NetApp ONTAP：エンタープライズ向け
- FSx for OpenZFS：UNIX系ワークロード

## インスタンスストア
- **EC2に物理直結された一時ストレージ**

### 特徴
- 超高速 I/O
- インスタンス停止でデータ消失
- キャッシュ・一時データ向け

## AWS Storage Gateway
- **オンプレとAWSをつなぐハイブリッドストレージ**

### 特徴
- オンプレのストレージを S3 に拡張
- バックアップやファイル共有をクラウド化
- ハイブリッド環境向け

## ストレージ使い分け
| サービス | 種類 | 向いている用途 |
|----------|--------|------------------------------|
| S3 | オブジェクト | 静的サイト、画像、ログ、配信 |
| EBS | ブロック | EC2 の OS / DB ディスク |
| EFS | ファイル | 複数 EC2 の共有ストレージ |
| S3 Glacier | アーカイブ | 長期保存・バックアップ |
| FSx | 高性能ファイル | Windows、HPC、企業向けFS |
| インスタンスストア | 一時 | キャッシュ・一時データ |
| Storage Gateway | ハイブリッド | オンプレ連携・容量拡張 |
