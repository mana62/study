# EC2
- 仮想サーバー
- インスタンスという単位
- AZに依存

## 特徴
| 特徴      | 一言でいうと                  |
| ------- | ----------------------- |
| 仮想サーバー  | クラウド上のLinux/Windowsサーバー |
| すぐ作れる   | 数分で起動可能                 |
| スペック選べる | CPU・メモリ自由に選択            |
| 台数増減できる | スケールしやすい                |
| 従量課金    | 使った分だけ料金                |
| OS選べる   | Linux / Windows         |
| 他AWSと連携 | S3、RDS、IAM等と連携          |

#### インスタンスファミリーとは
- **用途ごとに分けられたEC2サーバーの種類グループ**

| ファミリー  | 用途      | 一言      |
| ------ | ------- | ------- |
| T系     | 小規模・開発  | 安い汎用    |
| M系     | 一般用途    | バランス型   |
| C系     | CPU重視   | 計算速い    |
| R系     | メモリ重視   | DB向け    |
| X系     | 超大容量メモリ | 大規模DB   |
| P / G系 | GPU     | AI・画像処理 |
| I系     | 高速SSD   | I/O特化   |
| D系     | 大容量保存   | ストレージ特化 |

- T = 安い
- M = 普通
- C = CPU 計算系
- R = RAM メモリ系
- G/P = GPU

| 文字 | 意味                | 用途        |
| -- | ----------------- | --------- |
| T  | Burstable 汎用低コスト系 | 小規模・開発    |
| M  | General Purpose   | バランス型     |
| C  | Compute Optimized | CPU重視     |
| R  | Memory Optimized  | メモリ重視     |
| G  | GPU系              | グラフィック/AI |
| P  | GPU高性能系           | 機械学習      |

#### 世代とは
- そのインスタンスファミリーの新しさ・バージョン番号
- **数字が大きいほど、基本的に新しい世代**

簡単にいうとスマホでいう
- iPhone 13
- iPhone 14

みたいなもの

- インスタンスサイズ（容量・性能ランク）
- **同じファミリーの中で、CPU・メモリの大きさを示すサイズ名**

| サイズ        | イメージ | 用途        |
| ---------- | ---- | --------- |
| nano       | 最小   | 軽い検証      |
| micro      | 小    | 学習・小規模Web |
| small      | やや小  | 小規模業務     |
| medium     | 中    | 一般用途      |
| large      | 大    | 本番用途      |
| xlarge     | かなり大 | 高負荷       |
| 2xlarge 以上 | 超大   | 大規模処理     |

#### 2つのタイプがある
- EBSは永続的なブロックストレージ
- インスタンスストアはEC2ローカルの一時ストレージ


**① インスタンスストア**
- インスタンスストア = 一時作業用SSD
- **EC2ホストマシン内の一時ストレージ**
- 非常に処理速度が速いが、一時的なデータ保存
- 無料


**② EBS（Elastic Block Store）**
- EBS = 本番用ハードディスク
- **EC2にネットワーク接続して使う永続ディスク**
- 安定していて停止してもデータが残る
- EBS料金がかかる
- EC2とは独立して管理する


| 項目     | インスタンスストア         | EBS               |
| ------ | ----------------- | ----------------- |
| 保存場所   | EC2物理ホスト内ローカルディスク | AWSネットワーク越し永続ディスク |
| 速度     | 非常に速い             | 高速（安定）            |
| 停止でデータ | 消える場合あり           | 残る                |
| EC2終了時 | 消える               | 残せる               |
| 用途     | 一時データ・キャッシュ       | OS・DB・通常保存        |
