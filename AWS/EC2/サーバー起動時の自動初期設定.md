# サーバー起動時の自動初期設定

## ユーザーデータ
- ユーザーデータは、EC2起動時に実行されるスクリプトで、ブートストラップとして初期設定自動化に使う

- **ユーザーデータ** = EC2起動時に実行させる命令文（スクリプト）
- **ブートストラップ** = 起動直後に自動セットアップする仕組み全体

## ① ユーザーデータとは？
- **EC2作成時に入力できるスクリプト**

```bash
例（Linux）：
#!/bin/bash
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
```

これを入れて起動すると、
- Apacheインストール
- 起動
- 自動起動設定
まで勝手にやってくれる

## ② ブートストラップとは？
サーバーが起動したときに、
- OS初期設定
- ソフト導入
- 設定ファイル配置
- アプリ起動
などを自動で行うこと
ユーザーデータはその代表的な方法
