# EC2コスト
- 代表的なものは下記４つ

| 種類                        | 安さ | 向いてる用途 | 特徴         |
| ------------------------- | -- | ------ | ---------- |
| オンデマンド                    | 普通 | 検証・急ぎ  | 必要な時だけ使う   |
| Savings Plans / Reserved系 | 安い | 常時稼働   | 長期利用で割引    |
| スポット                      | 最安 | バッチ・検証 | 中断される可能性あり |
| Dedicated                 | 高い | 専用要件   | 専有ハードウェア   |

### ① オンデマンド（基本）
- 使った時間分だけ払う通常料金

例：
- 今日だけサーバー使う
- 開発環境
- 急に必要になった

メリット：
- すぐ使える
- 契約縛りなし

デメリット：
- 長期運用だと割高

### ② リザーブドインスタンス（Reserved Instances）
- 1年 or 3年使う約束で安くする
- 長期間使うEC2向け

例：
- 本番Webサーバー
- 常時起動DBサーバー

メリット：
- オンデマンドよりかなり安い

デメリット：
- 利用計画が必要

### ③ Savings Plans（今は人気）
- Reservedに近いですが、より柔軟
- 一定利用額を約束して割引
- EC2以外にも適用しやすい場合あり
- 現在は Reserved より選ばれやすいことがある

### ④ スポットインスタンス
- AWSの空き資源を激安で借りる
- 70〜90%安いこともある
- ただし、AWS都合で停止される可能性あり

向いてる用途：
- バッチ処理
- AI学習
- 一時処理
- CI/CD

向かない：
- 本番DB
- 常時必要サーバー

### ⑤ Dedicated Hosts / Dedicated Instances
- 自分専用の物理サーバー
- コンプライアンス要件向け
- 高価

## 実務でよくある組み合わせ
| 用途      | おすすめ                     |
| ------- | ------------------------ |
| 本番Web   | Savings Plans / Reserved |
| 開発環境    | オンデマンド                   |
| 夜間バッチ   | スポット                     |
| 金融・専有要件 | Dedicated                |
