# EBS
- **EC2に取り付けて使うディスク**（ストレージ）サービス
- AWS上の外付けSSD / HDD
- EC2停止後もデータ保持
- 99.999の可用性
- AZ単位で使用
- １つのインスタンスに複数のEBSを使用可能
- **EBSはスナップショットを利用してバックアップを取得**する
- 保存期間は世代数は無制限

- Amazon EC2 はサーバー本体
- EBSはそのサーバーに付ける保存用ディスク


## 特徴
| 特徴        | 内容         |
| --------- | ---------- |
| 永続保存      | EC2停止しても残る |
| 高速        | SSDタイプあり   |
| サイズ変更可    | 容量拡張可能     |
| スナップショット  | バックアップ可能   |
| 別EC2へ付替え可 | 条件付きで可能    |

## S3との違い
| 項目  | EBS    | S3        |
| --- | ------ | --------- |
| 使い方 | EC2に接続 | ファイル置き場   |
| 見え方 | ディスク   | オブジェクト保存  |
| 用途  | OS・DB  | 画像・バックアップ |

## 種類
| 種類  | 用途         |
| --- | ---------- |
| gp3 | 一般用途（おすすめ） |
| io2 | 高性能DB      |
| st1 | HDD大容量     |
| sc1 | 低コスト保管     |


## 2つのタイプ
- EBSは永続的なブロックストレージ
- インスタンスストアはEC2ローカルの一時ストレージ


**① インスタンスストア**
- インスタンスストア = 一時作業用SSD
- **EC2ホストマシン内の一時ストレージ**
- 非常に処理速度が速いが、一時的なデータ保存
- 無料


**② EBS（Elastic Block Store）**
- EBS = 本番用ハードディスク
- **EC2にネットワーク接続して使う永続ディスク**
- 安定していて停止してもデータが残る
- EBS料金がかかる
- EC2とは独立して管理する


| 項目     | インスタンスストア         | EBS               |
| ------ | ----------------- | ----------------- |
| 保存場所   | EC2物理ホスト内ローカルディスク | AWSネットワーク越し永続ディスク |
| 速度     | 非常に速い             | 高速（安定）            |
| 停止でデータ | 消える場合あり           | 残る                |
| EC2終了時 | 消える               | 残せる               |
| 用途     | 一時データ・キャッシュ       | OS・DB・通常保存        |
