# AWS データベース

# リレーショナルデータベース（RDB）
## Amazon RDS
フルマネージドなリレーショナルデータベース

### 特徴
- **MySQL / PostgreSQL / MariaDB / Oracle / SQL Server 対応**
- 自動バックアップ
- マルチAZ
- パッチ適用・メンテナンス自動化
- 運用負荷を大幅に削減

### 向いている用途
- 一般的な業務システム
- Webアプリのバックエンド
- トランザクションが必要なアプリ


## Amazon Aurora
**高性能・高可用性の分散型リレーショナルデータベース（RDSの上位版）**

### 特徴
- **MySQL / PostgreSQL 互換**
- 性能は **MySQL の最大 5倍**
- 99.99% 可用性
- **3つのAZ × 2コピー = 6コピーの分散ストレージ**
- 自動バックアップ・ポイントインタイムリカバリ
- 最大 15個のリードレプリカ（リードレプリカ：**読み取り専用の複製DB**、**読み込み負荷を分散するための仕組み**）
- 大量の同時読み書きに強い
- 従量課金でコスト最適化

### 向いている用途
- 大規模トラフィック
- ミッションクリティカルなアプリ
- 高可用性が必須のサービス

# 分析系データベース（DWH）

## Amazon Redshift
**ペタバイト級のデータウェアハウス（分析専用DB）**
※ ペタバイト：1PB（ペタバイト）＝1,000TB（テラバイト）＝100万GB、**超巨大データ量**

### 特徴
- サーバーレス対応
- **ゼロETL（Aurora / S3 から直接分析）**
- ※ ETL：**Extract → Transform → Load の略**、**データを取り出して、加工して、格納する処理**
- 自動WLM（ワークロード管理）
- データレイク連携（S3）
- 生成AI統合
- コスト最適化（スケール自動化）

### 向いている用途
- BI分析
- 大量データの集計
- データレイク＋DWH構成

# NoSQL データベース
## DynamoDB
**サーバーレスのキーバリュー型 NoSQL**

### できること
- キーに対する高速 CRUD
- 水平スケーリング（単一ではなく複数）
- サーバーレスで運用不要
- **リアルタイム処理に最適**

### できないこと
- JOIN
- 複雑なトランザクション
- リレーショナル構造

### 向いている用途
- 大量アクセス
- IoT
- ゲーム
- セッション管理

# DocumentDB / Keyspaces / Neptune / Timestream
用途特化型 NoSQL
| サービス     | 種類          | 用途                     |
|--------------|---------------|--------------------------|
| DocumentDB   | ドキュメントDB | MongoDB 互換             |
| Keyspaces    | カラム型       | Cassandra 互換           |
| Neptune      | グラフDB       | SNS・ネットワーク分析     |
| Timestream   | 時系列DB       | IoT・メトリクス          |

# インメモリキャッシュ
## ElastiCache（Redis / Memcached）
**超高速インメモリキャッシュ**（インメモリ：**データをメモリ（RAM）に保存して高速アクセスする方式**）

### 特徴
- ミリ秒以下の高速アクセス
- フルマネージド
- Redis / Memcached 対応
- セッション管理・ランキング・キャッシュに最適

# DynamoDB と ElastiCache の使い分け
| サービス      | 特徴                         | 向いている用途                     |
|---------------|------------------------------|------------------------------------|
| DynamoDB      | 永続データ、水平スケール       | 本番データ、ユーザー情報、ログ        |
| ElastiCache   | インメモリ、高速、揮発性        | キャッシュ、ランキング、セッション管理 |

# データベース使い分け
| 種類 | サービス | 向いている用途 |
|------|----------|----------------|
| リレーショナルDB | RDS | 一般的な業務アプリ |
| 高性能RDB | Aurora | 大規模・高可用性アプリ |
| 分析DB | Redshift | BI・大量データ分析 |
| NoSQL | DynamoDB | 高速・大規模・サーバーレス |
| キャッシュ | ElastiCache | 高速アクセス・一時データ |
