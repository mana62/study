# 通信プロトコルとIOSモデル

## 通信プロトコル
- **コンピューター同士が通信するためのルール**

### 例：メール送信
- メールを送る時のルール

| 用途 | プロトコル                            | 一言       |
| -- | -------------------------------- | -------- |
| 送信 | Simple Mail Transfer Protocol    | メール送る    |
| 受信 | Post Office Protocol version 3   | 受信してPC保存 |
| 受信 | Internet Message Access Protocol | サーバー同期受信 |

### 例：Webサイト閲覧
- ブラウザでサイトを見る時のルール

| 用途     | プロトコル                       |
| ------ | --------------------------- |
| Web閲覧  | Hypertext Transfer Protocol |
| 暗号化Web | HTTPS                       |

### 他の重要なプロトコル

| 用途     | プロトコル                  |
| ------ | ---------------------- |
| 名前解決   | Domain Name System     |
| リモート接続 | Secure Shell           |
| ファイル転送 | File Transfer Protocol |



## OSI参照モデル
- **通信を7階層に分けて整理した考え方**
- 通信を役割ごとに分けた設計図

| 層 | 名前         | 意味     |
| - | ---------- | -------- |
| 7 | アプリケーション層  | Web、メール  |
| 6 | プレゼンテーション層 | 暗号化、文字形式 |
| 5 | セッション層     | 接続管理     |
| 4 | トランスポート層   | TCP/UDP  |
| 3 | ネットワーク層    | IPルーティング |
| 2 | データリンク層    | MACアドレス  |
| 1 | 物理層        | ケーブル、電波  |

- 上3つ：アプリ側
- 真ん中：通信制御
- 下2つ：機械・配線

## TCP/IPモデル（TCP/IP参照モデル）
- **OSI参照モデルを、実際のインターネット通信向けにシンプル化した考え方**

### 比較
| OSI参照モデル | TCP/IPモデル     |
| -------- | ------------- |
| 7層       | 4層（または5層）     |
| 理論モデル    | 実務寄り          |
| 学習用によく使う | 現実ネットワークでよく使う |

## TCP/IP 4層モデル
| 層           | 内容              | OSI対応 |
| ----------- | --------------- | ----- |
| アプリケーション層   | HTTP, DNS, SMTP | 5〜7層  |
| トランスポート層    | TCP, UDP        | 4層    |
| インターネット層    | IP              | 3層    |
| ネットワークアクセス層 | LAN, Wi-Fi      | 1〜2層  |
