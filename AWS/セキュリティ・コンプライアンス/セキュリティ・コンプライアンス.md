# AWS セキュリティ & コンプライアンス
AWS のセキュリティは大きく 4カテゴリ に整理できる：
- ①**アプリ・ネットワーク保護**（WAF / Shield / Firewall）
- ②**暗号化・証明書管理**（KMS / CloudHSM / ACM）
- ③**自動検知**（GuardDuty / Inspector / Macie / Detective）
- ④**統制・ガバナンス**（Control Tower / Audit Manager / Artifact）

# 1. アプリケーション & ネットワーク保護
## AWS WAF
- **Webアプリを攻撃から守るファイアウォール（L7）**

### 特徴
- HTTP/HTTPS をリアルタイム監視
- SQLインジェクション / XSS などを防御
- 一時的な脆弱性にも対応
- CloudFront / ALB / API Gateway と連携

## AWS Shield
- **DDoS攻撃から AWS を保護**するサービス

### 種類
1. Standard（無料）
- 全AWSユーザーに自動適用
- エッジロケーションでDDoS防御

2. Advanced（有料）
- すべてのレイヤーを保護
- 24/7サポート、コスト保護、詳細レポート

## AWS Network Firewall
- **VPC 内の悪意ある通信をブロックするファイアウォール**（L3/L4）

### 特徴
- マルウェア通信・不正アクセスを防止
- VPCレベルでのネットワーク保護
- 大規模ネットワーク向け

## セキュリティの流れ
```bash
インターネット
   ↓
WAF / Shield（アプリ・DDoS防御）
   ↓
Network Firewall（VPC内部の通信制御）
   ↓
AWSリソース（EC2 / ALB / Lambda）
```

# 2. 暗号化サービス
## AWS KMS（Key Management Service）
- **暗号化キーを作成・管理するサービス**

### 特徴
- 99.99% 可用性
- 1年ごとの自動キーローテーション
- IAM でアクセス制御
- CloudTrail で監査
- S3 / EBS / RDS / Lambda などと連携

## AWS CloudHSM
- **ハードウェアセキュリティモジュール（HSM）**

### 特徴
- 鍵を専用ハードウェアで管理
- 金融・政府など高セキュリティ向け
- FIPS 140-2 レベル3準拠

## AWS Certificate Manager（ACM）
- **SSL/TLS証明書の作成・管理・自動更新**

### 特徴
- 無料で証明書発行
- 自動更新
- CloudFront / ALB / API Gateway と簡単連携

# 3. 自動検知サービス
## Amazon GuardDuty
- **脅威検知サービス（エージェント不要）**

### 特徴
- 96% 自動検出
- 機械学習で異常検知
- VPC Flow Logs / CloudTrail / DNS Logs を分析
- インフラ全体のリスクを可視化

## Amazon Inspector
- EC2 / ECR の脆弱性スキャン

### 特徴
- 継続的にスキャン
- ソフトウェアの脆弱性を自動検出
- コンテナイメージ（ECR）も対象

### Amazon Macie
- **S3 の機密情報（個人情報など）を自動検出**

### 特徴
- 機械学習＋パターンマッチ
- 個人情報・クレジットカード番号などを検出
- データ漏洩対策に有効

## Amazon Detective
- **ログを自動収集し、セキュリティインシデントを調査**

### 特徴
- GuardDuty / CloudTrail / VPCログを統合
- インシデントの原因分析を支援

# 4. 統制・ガバナンス
## AWS Control Tower
- **複数アカウントのガバナンスを自動化**

### 特徴
- ベストプラクティスに沿ったアカウント作成
- ガードレール（セキュリティルール）適用
- 大規模組織向け

## AWS Service Catalog
- **承認済みのリソーステンプレートを配布**

### 特徴
- 開発者が勝手に構成を変えないよう統制
- 企業標準の環境を提供

## AWS License Manager
- **ソフトウェアライセンスを一元管理**

## AWS Audit Manager
- **監査レポートを自動生成**

### 特徴
- セキュリティ基準（ISO、SOC、PCI）に対応
- 監査証跡を自動収集

## AWS Artifact
- **コンプライアンスレポートのダウンロード**

### 特徴
- AWS の認証・監査レポートを取得
- 契約書（BAAなど）も管理
