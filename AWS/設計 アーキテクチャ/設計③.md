# AWS 設計③
## AWS Well-Architected Tool
- **クラウド設計の健康診断ツール**
- 自分のAWS環境が、安全・効率的・コスト最適・障害に強い構成になっているかをチェックしてくれる無料ツール

## 良いクラウド設計の基準
1. 運用の優秀性（Operational Excellence）
ちゃんと運用しやすいか
2. セキュリティ（Security）
不正アクセス対策できてるか
3. 信頼性（Reliability）
障害が起きても止まりにくいか
4. パフォーマンス効率（Performance Efficiency）
無駄なく速く動くか
5. コスト最適化（Cost Optimization）
お金をムダ遣いしていないか
6. 持続可能性（Sustainability）
環境負荷を抑えられているか

## AWS Healthとの違い
- AWS Well-Architected Tool
→ あなたの設計が良いかチェックするツール
- AWS Health
→ AWS側で起きている障害・メンテ・影響情報を知らせるツール
