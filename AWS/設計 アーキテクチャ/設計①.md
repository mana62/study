# AWS 設計①
AZ
- １つのリージョンに2つのAZを利用してアーキテクチャを設計することが基本
- 両方のAZに、DBもマルチでEC2も付加分散する（ELB）
- 冗長性が高い設計をしておくことで一個壊れてもOK

VPC
- 1つのVPCでアーキテクチャを設計するのが基本
- ２つのVPCを使う場合は、開発環境・本番環境などで分ける

ネットワークの分割方法は下記2種類
- マルチVPC方式：VPC自体で役割を分けていく
- マルチアカウント方式：アカウント毎にVPCを分ける

サブネット
- サブネットは基本的にはプライベートサブネットを使用
- サイダーは/24以上が推奨されてる
- プライベートサブネットに多くのIPアドレスを割り当てる


マルチリージョン
- 別リージョンにデータベースのレプリカを配置するなどしてデータアクセスを分散する（リージョンが止まった時などの災害対応）
