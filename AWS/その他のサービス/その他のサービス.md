# AWS その他サービス

# 1. 分析・ビッグデータ系
## Amazon Athena
- **S3上のデータに SQLで直接クエリ**
- サーバーレス
- 使いどころ：ログ分析、S3データの即席集計

## Amazon EMR
- **Hadoop/Spark などの ビッグデータ処理基盤をマネージドで提供**
- 使いどころ：大量データの分散処理、ETL

## Amazon OpenSearch Service
- **全文検索・ログ分析**（Elasticsearch互換）
- 使いどころ：ログ検索、Kibanaダッシュボード

## AWS Glue
- **サーバーレス ETL**（データ変換・カタログ管理）
- 使いどころ：データレイクの前処理、ETLパイプライン

## AWS Data Exchange
- **外部データ（気象、金融、地図など）を マーケットプレイス形式で取得**
- 使いどころ：外部データを分析に活用したいとき

# 2. 可視化・BI
## Amazon QuickSight
- **サーバーレスBIツール**
- ダッシュボード作成
- 使いどころ：経営レポート、可視化

# 3. AI/機械学習（ML）
## Amazon SageMaker
- **MLモデルの 学習・デプロイ・管理をフルマネージド**
- 使いどころ：本格的な機械学習開発

## Amazon Comprehend
- **自然言語処理（NLP）**
- 感情分析、キーフレーズ抽出、分類など
- 使いどころ：レビュー分析、文章の自動分類

## Amazon Rekognition
- 画像・動画分析
- 顔認識、物体検出、テキスト抽出
- 使いどころ：監視カメラ、画像分類

## Amazon Textract
- スキャン文書から 構造化データを抽出
- 使いどころ：請求書・帳票の自動読み取り

## Amazon Translate
- 高精度の自動翻訳
- 使いどころ：多言語サイト、文書翻訳

## Amazon Polly
- テキスト → 音声変換（TTS）
- 使いどころ：読み上げサービス、音声アプリ

## Amazon Transcribe
- 音声 → テキスト変換（STT）
- 使いどころ：会議録起こし、コールセンター分析

## Amazon Lex
- チャットボット構築（音声/テキスト）
- 使いどころ：問い合わせ自動化、音声ボット

## Amazon Q
- AWS向けの 生成AIアシスタント
- コード生成、AWS設定支援、ドキュメント検索
- 使いどころ：開発効率化、AWS運用支援

# 4. 検索・ナレッジ系
# Amazon Kendra
- 企業内検索エンジン
- PDF、Word、SharePoint、S3などを横断検索
- 使いどころ：社内ナレッジ検索
