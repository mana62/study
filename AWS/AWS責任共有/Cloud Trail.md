# CloudTrail
**AWSアカウント内の操作履歴を記録するサービス**
→ 誰が、いつ、どこから、何をしたかを記録

## 何を記録するのか？
- 誰が実行したか（IAMユーザー、ロール）
- いつ実行したか
- どのIPアドレスからか
- 何のサービスに対してか
- 成功したか失敗したか
- 変更内容

## 主な用途
### ① API操作記録
- 誰が何したか追跡できる

例：
- 誰がS3削除した？
- 誰がIAM権限変更した？

### ② ログ収集
- 操作履歴をS3へ保存できる
- 長期保存・監査対応に使う

### ③ イベント通知
- 特定操作があったら通知できる

例：
- ルートユーザーがログインした
- IAMポリシー変更された
- EventBridge + SNS連携など

### ④ 分析・監視
- CloudWatch LogsやAthenaで分析可能

例：
- 深夜の不審アクセス調査
- 特定ユーザーの操作確認

### ⑤ 可視化
- CloudTrail Event Historyで簡単に確認可能
- AWSコンソール上で最近90日見られる

## 組織トレイル（Organizations連携）とは？
**複数AWSアカウントをまとめてログ取得する仕組み**


## 利点
### ① 全アカウント一括監査
- 会社で複数アカウントあっても全部まとめて管理可能

例：
- 開発アカウント
- 本番アカウント
- 検証アカウント
全部追跡できる

### ② マルチリージョン対応
- 東京リージョンだけでなく、

- 東京
- 大阪
- バージニア
- シンガポール
など全リージョン対象可能

### ③ セキュリティ強化
- 各アカウントで設定漏れが起きにくい
- 管理アカウントから強制的に取得できる

## よく比較されるサービス
**CloudTrail**
→ 誰が何をしたか（操作ログ）

**CloudWatch**
→ AWS上のサーバー・アプリ・ログ・インフラをまとめて監視するサービス

**Config**
→ 設定変更履歴
