# AWS マネジメント & ガバナンス
AWS の運用管理は 3フェーズ に整理できる：

```bash
準備（Governance Setup）
   ↓
展開（Provisioning）
   ↓
操作（Operations）
```

# 1. 準備フェーズ（Governance Setup）
- **マルチアカウント環境の設計・統制を整える段階**

## AWS Control Tower
- **マルチアカウント環境の自動構築・ガバナンス適用**（推奨）
- ベストプラクティスに沿ったアカウント作成
- ガードレール（セキュリティルール）自動適用
- Organizations と連携して統制を強化

## AWS Organizations
- **複数アカウント管理の基盤**
- OU（組織単位）で階層管理
- SCP（サービスコントロールポリシー）で制限
- 請求統合（Consolidated Billing）

## AWS Budgets
- **コストの予算設定・アラート**
- 予算超過をメール通知
- コスト管理の基本ツール

# 2. 展開フェーズ（Provisioning）
- **インフラを自動化して展開する段階**

## AWS CloudFormation
- **JSON/YAML でインフラをコード化（IaC）**
- 再現性のある環境構築
- バージョン管理可能
- 大規模環境の標準化に必須

## AWS Elastic Beanstalk
- **アプリケーションのデプロイ自動化**
- コードをアップロードするだけで環境構築
- EC2 / ALB / Auto Scaling を自動設定
- 開発者向けの簡易PaaS

## AWS Service Catalog
- **承認済みテンプレートを配布する仕組み**
- 開発者が勝手に構成を変えないよう統制
- 企業標準の環境を提供

## AWS Marketplace
- サードパーティ製品の購入・デプロイ
- セキュリティ製品、OS、DB、SaaSなどを簡単導入

# 3. 操作フェーズ（Operations）
- **運用・監視・変更管理を行う段階**

## AWS Personal Health Dashboard
- **AWS側の障害・メンテナンス情報を通知**
- 自分の環境に影響するイベントだけを表示
- 障害時の影響範囲を把握しやすい

## AWS Config
- **設定変更の追跡・監査・準拠性チェック**

### できること
- **ストリーム**：設定変更イベントをリアルタイム検知
- **ヒストリー**：過去の設定履歴を保存
- **スナップショット**：現在の設定を丸ごと記録
- 準拠性チェック（コンプライアンス）

## AWS Trusted Advisor
- **コスト・セキュリティ・信頼性・パフォーマンスの診断**
- 無駄なリソースの削減
- セキュリティの改善点を提案
- 制限（Service Quotas）の確認
- ビジネス/エンタープライズサポートで全機能解放

# AWS サポートプラン
| プラン       | 内容                                   |
|--------------|----------------------------------------|
| Basic        | 無料、ドキュメント・フォーラム利用可能     |
| Developer    | 開発者向け、営業時間サポート               |
| Business     | 24/7サポート、Trusted Advisor 全機能       |
| Enterprise   | TAM（専任担当）、統合運用支援              |

# まとめ
| フェーズ | サービス | 役割 |
|----------|-----------|-------|
| 準備 | Control Tower | マルチアカウント自動構築・ガバナンス |
| 準備 | Organizations | アカウント統制・SCP・請求統合 |
| 準備 | Budgets | コスト予算管理 |
| 展開 | CloudFormation | IaC（インフラ自動構築） |
| 展開 | Elastic Beanstalk | アプリ自動デプロイ |
| 展開 | Service Catalog | 承認済みテンプレート配布 |
| 展開 | Marketplace | サードパーティ製品導入 |
| 操作 | Personal Health Dashboard | AWS障害の影響通知 |
| 操作 | AWS Config | 設定変更追跡・準拠性チェック |
| 操作 | Trusted Advisor | コスト/セキュリティ診断 |
| 操作 | Support Plans | AWSサポート |
