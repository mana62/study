# AWS CAF（Cloud Adoption Framework）
- AWSが数千社のクラウド移行支援で得た知見を体系化した. **クラウド導入の総合フレームワーク**

- 組織のクラウド準備度を評価
- 課題を6つの視点で整理
- 移行ロードマップを作成
- リスクを最小化しながら変革を加速
6つの視点は AWS 公式でも明確に定義されている

# AWS CAF：6つのパースペクティブ（視点）
## 1. ビジネス（Business）パースペクティブ
**クラウド投資がビジネス成果に直結するかを評価する視点**

- 経営戦略との整合性
- コスト最適化
- 新規事業・イノベーション
- 価値創出の最大化

**経営層（CEO/CFO/CIO）が主なステークホルダー**

## 2. 人材（People）パースペクティブ
**クラウドを扱う人と組織の変革にフォーカス**

- スキル育成（クラウド習熟）
- 組織文化の変革
- 役割・体制の再設計
- リーダーシップと変革推進

AWSは **「文化・スキル・組織構造の進化」が重要と強調**

## 3. ガバナンス（Governance）パースペクティブ
**クラウド導入を統制しながら進めるための視点**

- コンプライアンス
- 予算管理・コスト統制
- リスク管理
- ポリシー・標準化

**CFO、CIO、リスク管理部門が関与**

## 4. プラットフォーム（Platform）パースペクティブ
**クラウド上の技術基盤（インフラ・アプリ）をどう構築するか**

- ネットワーク、コンピュート、ストレージ
- CI/CD、IaC
- モダナイゼーション
- ハイブリッド構成

**CTO・アーキテクト・エンジニアが中心**

## 5. セキュリティ（Security）パースペクティブ
**クラウド環境の安全性・コンプライアンスを確保する視点**

- データ保護（暗号化、KMS）
- IAM・アクセス管理
- 監査・ログ管理
- セキュリティアーキテクチャ

**CISO・セキュリティチームが担当**

## 6. オペレーション（Operations）パースペクティブ
**クラウド運用を安定・効率化するための視点**

- モニタリング（CloudWatch）
- インシデント管理
- 自動化（IaC、運用自動化）
- SRE的アプローチ

**運用チーム・SREが主担当**

# まとめ
**AWS CAF = 組織全体を6視点でクラウド対応に変革するフレームワーク**


| 視点 | 目的 |
|------|------|
| ビジネス | 事業価値・戦略整合 |
| 人材 | スキル・文化・組織 |
| ガバナンス | ルール・予算・リスク |
| プラットフォーム | 技術基盤 |
| セキュリティ | 安全性・コンプライアンス |
| オペレーション | 運用・自動化 |
