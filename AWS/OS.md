# OS
- OSとは **Operating System**（オペレーティングシステム）
- **コンピューターを動かすための基本ソフトウェア**
- 簡単にいうと人がアプリを使えるように、**パソコンやサーバーを管理してくれる土台のソフト**

| もの   | 例                             | 何か         |
| ---- | ----------------------------- | ---------- |
| PC本体 | ノートPC、デスクトップ                  | 機械（ハードウェア） |
| OS   | Microsoft Windows, macOS      | 基本ソフト      |
| アプリ  | Google Chrome, Microsoft Word | 利用ソフト      |


## 例
PCなら：
- Microsoft Windows
- macOS

スマホなら：
- Android
- iOS

サーバーなら：
- Ubuntu
- Amazon Linux
- Red Hat Enterprise Linux

## OSの役割
| 役割     | 内容             |
| ------ | -------------- |
| ハード制御  | CPU・メモリ・ディスク管理 |
| アプリ実行  | ソフトを動かす        |
| 画面操作   | マウス・キーボード受付    |
| ファイル管理 | 保存・読み込み        |
| ネット接続  | 通信機能           |


## AWSでいうと
- Amazon EC2 = 仮想PC本体（サーバー本体）
その中に

- Ubuntu
- Amazon Linux
- Microsoft Windows Server
などのOSを入れて使う
