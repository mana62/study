# サブネットとサブネットマスク
- **サブネット** = ネットワークを小さく分けた区画
- **サブネットマスク** = **どこまでがネットワーク範囲かを示すルール**

## イメージ
- 住所：東京都 新宿区 西新宿 1-1

このとき、
**東京都新宿区まで = 同じエリア**
**その先 = 個別住所**

ネットワークでも同じで、
- 192.168.1.10
**このIPのどこまでが「同じ地域」かを決めるのがサブネットマスク**

## ① サブネットとは？
- **大きいネットワークを分割した小グループ**

例：
会社ネットワーク全体
192.168.0.0/16

これを分けて：
- 営業部 192.168.1.0/24
- 開発部 192.168.2.0/24
- 管理部 192.168.3.0/24
**これらがサブネット**

## ② サブネットマスクとは？
- IPアドレスのうち、どこまでがネットワーク部分かどこからが機器番号かを決めるもの

例：255.255.255.0

これは、192.168.1.xxxまで同じネットワークという意味

## CIDR表記
- 192.168.1.0/24

これは、**/24 = 24ビットがネットワーク部使える台数 約254台**

AWSでの例：Amazon VPC
VPC: 10.0.0.0/16

その中に：
Public subnet  10.0.1.0/24
Private subnet 10.0.2.0/24

```bash
イメージ図
VPC（マンション全体）
└─ サブネット（各フロア）
    └─ EC2（部屋）
よく出る /24 の意味
192.168.1.0/24
```

使えるIP：192.168.1.1 ～ 192.168.1.254

### よく使われるサイダー
| CIDR | 残りビット | 利用可能台数(概算) |
| ---- | ----- | ---------- |
| /24  | 8     | 254        |
| /25  | 7     | 126        |
| /26  | 6     | 62         |
| /27  | 5     | 30         |

255の場合は全部1

## まとめ
- サブネットマスクを設定することで同じネットワークで扱うIPアドレスの範囲を指定できる
- このIPアドレス範囲をCIDRと呼ぶ
-  CIDRを指定してプライベートネットワークをサブネットに分けることができる
