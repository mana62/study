# ルートテーブル
- 信先ごとに、どこへ送るかを決める交通案内表（経路表）


例：
| 宛先          | 送信先              |
| ----------- | ---------------- |
| 10.0.0.0/16 | ローカル             |
| 0.0.0.0/0   | Internet Gateway |


## 0.0.0.0/0
- デフォルトGW

## Private subneの例
| 宛先          | 送信先         |
| ----------- | ----------- |
| 10.0.0.0/16 | ローカル        |
| 0.0.0.0/0   | NAT Gateway |

## ルートテーブルはどこに適用するのか
- **サブネット単位**
