# サブネット
- パブリックサブネットとプライベートサブネットの2種類
- プライベートサブネットには、NATゲートウェイを置く必要がある
- NATゲートウェイは、パブリックサブネット内に置く必要がある
- VPC内で設定
- 最初はプライベートサブネットとして作られる
- インターネットGWのルートを加えることで、パブリックサブネットになる

## 
| ゲートウェイ種類        | 正式名称                         | 一言でいうと              | どこに付くか / 接続先                        | 主な用途                |
| --------------- | ---------------------------- | ------------------- | ----------------------------------- | ------------------- |
| IGW             | Internet Gateway             | VPCをインターネットにつなぐ出口   | **VPCにアタッチ**                        | Public subnet公開     |
| NAT GW          | NAT Gateway                  | Private subnetの代理出口 | **Public subnet内に配置**（Elastic IP付与） | Private subnet外向き通信 |
| VGW             | Virtual Private Gateway      | AWS側VPN受け口          | **VPCにアタッチ**                        | Site-to-Site VPN    |
| TGW             | AWS Transit Gateway          | VPC接続ハブ             | **独立サービス。VPC/VPN/DXをアタッチ**          | 多拠点接続               |
| CGW             | Customer Gateway             | 会社側VPN装置            | **オンプレ側ルーター/FW**                    | AWSとのVPN接続          |
| Egress-Only IGW | Egress-Only Internet Gateway | IPv6外向き専用出口         | **VPCにアタッチ**                        | IPv6 Private通信      |
| Local Gateway   | Local Gateway                | Outpostsとローカル接続     | **Outpostsに関連付け**                   | ハイブリッド              |
| Carrier Gateway | Carrier Gateway              | 通信キャリア網出口           | **Wavelength ZoneのVPCサブネットで利用**     | 5G低遅延通信             |
