# S3
- **インターネット上の巨大な保存庫（ストレージ）**
- ファイルを保存して、必要な時にいつでも取り出せるクラウド倉庫

## 保存できるもの
- 画像
- 動画
- PDF
- バックアップ
- ログファイル
- HTML/CSS/JS
- CSV / Excel
など

## 特徴
### ① オブジェクトストレージ形式
- S3はファイルをそのまま保存するイメージ
- ファイル = オブジェクト

### ② 容量ほぼ無制限
- 必要に応じてどんどん保存できる

### ③ 高耐久性
- AWS公式で非常に高い耐久性（99.999999999%）
- データ消失しにくいよう複数設備に保存される
- バックアップ用途でも強い

### ④ 従量課金
- 使った分だけ支払い
- 保存容量
- 通信量
- リクエスト回数

### ⑤ セキュリティ
- IAM制御
- バケットポリシー
- 暗号化
- 公開/非公開設定

### ⑥ ストレージクラス
- 利用頻度に応じて安い保存方法を選べる

## S3のユースケース
1. CMS 画像アップロード
2. S3
3. ClouldFront キャッシュ＆配信
```bash
S3 に画像保存
 ↓
CloudFront が世界へ高速配信
```
4. クライアント 高速閲覧

## 3つのストレージタイプ
### ① ブロックストレージ
- 例：Amazon EBS
- サーバーのディスク

用途：
- EC2のCドライブ
- OSインストール
- DBディスク

### ② オブジェクトストレージ
- 例：S3

用途：
- 画像
- 動画
- バックアップ
- ログ

### ③ ファイルストレージ
- 例：Amazon EFS
- 共有フォルダ形式

用途：
- 複数EC2で共有ファイル


## S3構造
S3の中にバケット（ストレージ単位）を用意（一位の名前である必要）

```bash
S3
└── バケット
      ├── img/a.jpg
      ├── img/b.jpg
      └── backup/db.sql
```

## バケットとは？
- S3の入れ物（フォルダの親玉）

特徴：
- 世界で一意の名前
- リージョン指定可能

例：
- my-company-image-bucket

## ストレージクラスの選択
### 1. Standard
- よく使うデータ向け
- 高速
- 高可用性
- 通常これ

### 2. Standard-IA
- たまに使うデータ向け
- 安い

例：
- 月1回見る資料

### 3. One Zone-IA
- 1AZ保存でさらに安い
- 重要データには慎重に

### 4. Intelligent-Tiering
- 自動で最適クラス移動
- 初心者にもかなりおすすめ

## S3の利用コスト
### 1. リージョン
- 東京はやや高め、海外安い場合あり

### 2. 保存容量
- 100GB保存など

### 3. リクエスト料金
- PUT（保存）
- GET（取得）
- LIST
- 大量アクセスで影響あり

### 4. データ転送
- 外部への大量配信で費用発生
- CloudFront活用多い

## リクエスタ支払い
- 取得した人に通信費負担させる設定
- 公開データ配布などで使うことあり

## バージョン管理
- ファイル更新しても旧版保持できる

```bash
report.xlsx
v1
v2
v3
```
- 誤削除対策にも強い

## S3 MFA Delete
- 削除時に多要素認証要求
- 超重要データ向け

## S3イベント
- ファイル追加時に自動処理できる

例：
```bash
画像アップロード
↓
Lambda起動
↓
サムネイル生成
```
