# データベース基礎
## データベースとは？
**データを整理して安全に保存し、すぐ使えるようにした仕組み**

## DBMS
**データベースを管理・操作するソフト**

代表例：
- MySQL
- PostgreSQL
- Oracle Database

## DBのデータ操作
データ管理の基本4操作（**CRUD**）
- Create：追加
- Read：見る
- Update：変更
- Delete：削除

## データベースとストレージ
保存場所（ストレージ）だけではDBではない

- ストレージ = 置き場
- DBMS = 管理人
**この2つでデータベースになる**

## データベースの役割
- データ保存
- 高速検索
- 更新管理
- 複数人同時利用
- 安全管理
- バックアップ

## トランザクション
**一連の処理をまとめて成功/失敗させる仕組み**

例：銀行振込
- A口座から減らす
- B口座へ増やす
両方成功しないとダメ

## トランザクション：ACID
信頼できるDBの4原則
- A（Atomicity）原子性：全部成功 or 全部失敗
- C（Consistency）整合性：ルールが壊れない
- I（Isolation）独立性：同時処理でも干渉しにくい
- D（Durability）永続性：完了したら消えない

## データモデル
**データをどういう形で保存するかの設計方法**

## データモデルのタイプ
### リレーション型
- **表（テーブル）形式**
- 例：会員テーブル、商品テーブル
- 一番よく使う

###  グラフ型
- 人や物のつながり重視
- 例：SNS友達関係

### キーバリュー型
- **キーと値の組み合わせ**
- 例：user001 = 山田
- 高速キャッシュ向け

### オブジェクト型
- **オブジェクト単位で保存**
- プログラムと相性良い

### ドキュメント型
- **JSON形式など柔軟保存**
- 例：MongoDB

### ワイドカラム型
- **大量データ分析向け**
- 例：ログ、IoT

### 階層型
- **親子関係で保存**
- 例：組織図、フォルダ構造
