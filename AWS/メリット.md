# AWSのメリット
## IaaSとしてのAWS
- AWSの基本はIaaS

```bash
VPC → ELB（負荷分散）→ サブネット → EC2（サーバー） → S３(ストレージ) → Route53（DNS、IP変換）
```

## PaaSとしてのAWS
- IaaSに加えて、アプリケーション開発ツールを利用

①コーディングツール = Cloud9
②コード管理・デプロイ支援ツール = Codeシリーズ（code commitなど）/Elastic BeansStalk/Gitなど
③開発環境のインフラ = EC2/RDS/VPCなど

## SaaSとしてのAWS
- 既にAWSで作られているものを使用
- APIを借りてきて使用
