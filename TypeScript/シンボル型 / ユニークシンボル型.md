# シンボル型 / ユニークシンボル型

## シンボル型とは
- JSのプリミティブ型の一つ
- 絶対に重複しない値のこと

```ts
const id1 = Symbol("id");
const id2 = Symbol("id");

console.log(id1 === id2); // false（値が同じでも、シンボル型は絶対に重複しない）
```

## ユニークシンボル型とは
- ユニークシンボル型 は **シンボル型よりさらに厳格で、「このシンボルと全く同じ型」を表す**
- 使える場所が **const の型注釈**かクラスの **static readonly プロパティのみ**に限られる
- 理由は、「この変数には絶対に1つの値しか入らない」と保証できる場所でないと意味がないから
- typeof と組み合わせる理由は、**unique symbol という型を型注釈として直接別の場所で書けないため、typeof mySymbol でその型を参照する**のがルールになっている

```ts
// ❌ エラー
let a: unique symbol
// ↑ letはNG
const b: symbol // (広すぎ)
```

```ts
// ⭕️ 正しい
const a: unique symbol // 必ずconst
= Symbol()
typeof a // で型取得もOK
```

## 使いどころ
- オブジェクトのキーに使うと、外から絶対に上書きできないプロパティが作れる
- ライブラリのプライベートIDなど「衝突してはいけない値」に使う


## ⚠️ ユニークシンボルが使える場所はとても限られる
　① const宣言の型注釈 だけ　
　② classのstatic readonly プロパティの型注釈 だけ
　理由：「この値は絶対に1つだけ」と保証できる場所でないと意味がないから

## typeofと一緒に使う理由
- type MyId = typeof a ← これで「aと同じユニークシンボル」という型が作れる
- unique symbolは型の名前で直接書けないので、typeofで取り出すのがルール

| 用語 | 一言でいうと | 補足 |
|------|--------------|------|
| symbol | 絶対に被らない値 | 毎回違う値になる特殊なプリミティブ |
| unique symbol | **型としても唯一の symbol** | "この1つだけ" を表す型になる |
| unique symbol が使える場所が限定 | 値が変わらない場所でしか使えない | const や readonly static にしか使えない |
