# デコレータ
**クラス自体やクラスのメソッド**に対して、**追加の処理**を**定義時**に差し込む仕組み

## 特徴
- @ を使う特別な関数
- クラスに新しい機能を付けるための仕組み
- メタプログラミング（コードを操作するコード）

👉 デコレータ = **クラスに対して実行される関数**
インスタンス生成時ではなく、クラスが **読み込まれた瞬間**に実行される

## 使うための
⚠️ **JSにはまだなく、将来的にJSに組み込まれるもの、提案段階**

→ そのため使うには設定が必要

- **ファイル：** `tsconfig.json`
- **設定：**
```ts
{
  "experimentalDecorators": true
  // trueにする必要がある
  // 実験的なものも使用するかという項目
}
```

## 各書き方
### ①クラスデコレータ
```ts
// 定型文
function Deco(target: Function) {}
```

```ts
// 例
function Logging(target: Function) {
  console.log("Class loaded:", target.name);
}

// ここに置くとクラス全体に適用される
@Logging
class User {}
```
動き：
- @Logging が クラス定義の瞬間に実行される
- new User() しなくても実行される

使い所：
- クラス読み込み時にログを出す
- DI コンテナ登録
- メタ情報付与（フレームワークで多い）

### ②デコレータファクトリー（引数を渡す）
```ts
// 定型文
function MyDecorator(message: string) { // ここで引数
  return function (target: Function) {
    // message を使った処理
  };
}
```
```ts
// 例
function Logging(message: string) {
  return function (target: Function) {
    console.log(message, target.name);
  };
}

@Logging("Loading class:") // 引数を渡せる
class User {}
```
動き：
- Logging("Loading class:") がまず実行される
- その返り値の関数がデコレータとして実行される

使い所：
- デコレータに設定値を渡したいとき
- ログレベル、オプション、メッセージなど

### ③メソッド
```ts
// 定型文
function LogMethod(
  target: any,
  propertyKey: string,
  descriptor: PropertyDescriptor
) {
  // メソッドに対する処理
}
```

```ts
// 例
function LogMethod(target: any, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value;

  descriptor.value = function (...args: any[]) {
    console.log(`Method called: ${key}`);
    return original.apply(this, args);
  };
}

class User {
  @LogMethod
  sayHello() {
    console.log("Hello!");
  }
}

new User().sayHello();
```
動き：
- sayHello が呼ばれる前にログが出る
- descriptor.value を書き換えてメソッドをラップできる

使い所：
- ログ
- 権限チェック
- メソッドの実行時間計測
- メソッドのラップ処理

### ④プロパティ
```ts
// 定型文
function LogProperty(target: any, propertyKey: string) {
  // プロパティに対する処理
}
```

```ts
// 例
function LogProperty(target: any, key: string) {
  console.log("Property:", key);
}

class User {
  @LogProperty
  name = "taro";
}
```
動き：
- クラス定義時に「name」というプロパティ名がログに出る
- 値にはアクセスできない（descriptor がないため）

使い所：
- メタ情報付与
- バリデーション設定（class-validator など）

### ⑤ アクセサデコレータ
```ts
// 定型文
function LogAccessor(
  target: any,
  propertyKey: string,
  descriptor: PropertyDescriptor
) {
  // getter/setter の処理
}
```
```ts
// 例
function LogAccessor(target: any, key: string, descriptor: PropertyDescriptor) {
  const originalSet = descriptor.set;

  descriptor.set = function (value: any) {
    console.log(`Setting ${key} to`, value);
    originalSet?.call(this, value);
  };
}

class User {
  private _age = 0;

  @LogAccessor
  set age(value: number) {
    this._age = value;
  }

  get age() {
    return this._age;
  }
}

const u = new User();
u.age = 30;
```
動き：
- setter が呼ばれるたびにログが出る
- 値の監視・制御ができる

使い所：
- 値の監視
- バリデーション
- 読み書きの制御

## ⑥ パラメータデコレータ
```ts
// 定型文
function LogParameter(target: any, propertyKey: string, parameterIndex: number) {
  // 引数に対する処理
}
```
```ts
// 例
function LogParameter(target: any, key: string, index: number) {
  console.log(`Parameter in method ${key} at position ${index}`);
}

class User {
  greet(@LogParameter message: string) {
    console.log(message);
  }
}

new User().greet("Hello");
```
動き：
- greet の第 0 引数にデコレータが付いていることがわかる
- 実際の値にはアクセスできない

使い所：
- DI（NestJS の @Inject()）
- 引数のバリデーション設定

## ⑦ 簡易フレームワーク系（Component の定型文）
```ts
// 定型文
function Component(template: string, selector: string) {
  return function (constructor: Function) {
    const el = document.querySelector(selector);
    if (el) {
      el.innerHTML = template;
    }
  };
}
```

```ts
// 例
@Component('<h1>Hello {{ name }}</h1>', '#app')
// 第一引数：入れたい文言
// 第二引数：第一引数を入れる場所（#appのidがある部分に入れる）
class User {
  name = "Taro";
}
```
動き：
- #app の要素を探す
- 見つかったら HTML を差し込む
- Angular の @Component の超簡易版

使い所：
- UI フレームワークの基礎
- HTML を差し込む
- コンポーネントの仕組みを理解する練習

## ⚠️ 注意点
❗ 1. 実行タイミングに注意
- クラス定義時に実行される
- new した時ではない

❗ 2. 実際のプロダクトでは乱用しない
- 便利だけど「何が起きてるか見えにくい」
- フレームワークでは便利だが、素のTSでは使いすぎ注意

❗ 3. メソッド・プロパティにも使えるが、仕様が複雑
- クラスデコレータ
- メソッドデコレータ
- アクセサデコレータ
- プロパティデコレータ
- パラメータデコレータ
などがある

## まとめ
- デコレータは クラスに対して実行される関数
- @Something の形で書く
- クラス定義時に実行される
- 引数を渡したい時は デコレータファクトリー
- フレームワークでよく使われる（Angular / NestJS）
- メタプログラミングの一種

| 種類       | 定型文                                      | キー情報               |
|------------|---------------------------------------------|------------------------|
| クラス     | `function Deco(target)`                     | クラス定義時に実行     |
| ファクトリー | `function Deco(arg){ return (target)=>{} }` | 引数を渡せる           |
| メソッド   | `(t, key, d)`                               | `d.value` を書き換えられる |
| プロパティ | `(t, key)`                                  | descriptor なし        |
| アクセサ   | `(t, key, d)`                               | getter/setter を操作   |
| パラメータ | `(t, key, index)`                           | 何番目の引数か         |
| Component  | `(template, selector)`                      | HTML を差し込む        |
