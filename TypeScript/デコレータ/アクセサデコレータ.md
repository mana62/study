# アクセサデコレータ
アクセサデコレータは **「getter/setter の裏設定（PropertyDescriptor）を書き換えるためのデコレータ」**

- メソッドデコレータと同じで引数は３つ取る
- 対象のメソッド（get or set）の上に@を書く
- 使わない引数の前には_を置く

## 引数
- 第一引数：target = メソッドが属するオブジェクト（prototype）
- 第二引数： propertyKey = メソッド名
- 第三引数： descriptor ＝ メソッドの中身（書き換え可能）

⚫︎第三引数を、返すことによって、裏設定を変えられる

第一引数は、スタティックであればクラス・staticでなければプロトタイプ
第二引数、プロパティーキー・メソッド名
第三引数、裏設定

## 例
```ts
function LogAccessor(target: any, key: string, descriptor: PropertyDescriptor) {
  const originalGet = descriptor.get;

  descriptor.get = function () {
    console.log("GET:", key);
    return originalGet?.call(this);
  };

  return descriptor; // ← 裏設定を書き換えたので返す
}

class User {
  private _name = "Taro";

  @LogAccessor
  get name() {
    return this._name;
  }
}

const u = new User();
console.log(u.name);

// 結果
GET: name
Taro
```


## 引数の意味
| 引数 | 内容 | 例 |
|------|------|------|
| target | メソッドが属するオブジェクト | インスタンス → User.prototype / static → User |
| propertyKey | アクセサ名（get/set の名前） | "name" |
| descriptor | 裏設定（PropertyDescriptor） | { get: ..., set: ..., enumerable: ..., configurable: ... } |

## 裏設定（PropertyDescriptor）
- **プロパティディスクリプタ**

```ts
{
  get: function() { ... },
  set: function(value) { ... },
  enumerable: false,
  configurable: true
}
```
- getter の中身
- setter の中身
- enumerable（列挙可能か）
- configurable（再定義可能か）
などの 内部設定 をまとめたもの

## アクセサデコレータの本質
**descriptor を書き換えることで、getter/setter の動作を差し替えられる**
👉 これがアクセサデコレータの最大の特徴

## 使わない引数に _ を置く理由
```ts
function Deco(_target: any, key: string, descriptor: PropertyDescriptor) {}
```
TypeScript のルールで：
- 使わない変数は `_`を付けると **「未使用でもOK」扱いになる**
- コードの意図が明確になる（読みやすい）

## ⚠️ 注意点
### ① アクセサデコレータは get/set のどちらか一方にしか付けられない
- **両方に付けたい場合は両方に書く必要がある**

### ② descriptor を返さないと書き換えが反映されない
- メソッドデコレータと同じ

```ts
return descriptor; // これが重要
```

### ③ プロパティデコレータとは全く別物
- プロパティデコレータは descriptor を受け取れないため、
裏設定を書き換えられない
- アクセサデコレータは descriptor を操作できるので強力

## まとめ

| 項目 | 内容 |
|------|------|
| 目的 | getter/setter の裏設定（descriptor）を書き換える |
| 引数 | target / propertyKey / descriptor |
| できること | getter/setter の動作を差し替える、ログ追加、バリデーションなど |
| 注意点 | descriptor を返す必要がある、get/set どちらかにしか付けられない |
