# 簡易フレームワーク系（Component）
- デコレーターを使って、**HTMLに自動で表示を追加する仕組みを作る**

具体的に：
1. クラスを書く
2. そのクラスに「デコレーター」をつける
3. すると
  - HTMLの特定の場所に
  - テンプレート（HTML文字列）を差し込む
  - さらにクラスのデータ（nameなど）を埋め込む

#### 通常
```ts
class User {
  name = "Quill";
}
```
👉 これだけだと何も起きない

#### デコレータ
```ts
@Component("<h1>{{name}}</h1>", "#app")
class User {
  name = "Quill";
}
```
👉 こうなる

```ts
<div id="app">
  <h1>Quill</h1>
</div>
```

## デコレーターの役割
- クラスが作られた瞬間に実行される
- クラスの「設計図（コンストラクタ）」を受け取る
- そこからインスタンスを作る
- プロパティ（name）を取り出す
- HTMLを書き換える
