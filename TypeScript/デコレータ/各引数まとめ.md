# 各引数まとめ

## ①プロパティデコレータ（引数２つ）
- 第一引数は：スタティックであればクラス・staticでなければプロトタイプ
- 第二引数：プロパティーキー・プロパティー名

```ts
function Log(target: any, key: string) {}
```
補足：
- **static** → **コンストラクタ関数（クラス自身）**
- **instance** → **prototype**

## ②メソッドデコレータ（引数３つ）
- 第一引数：スタティックであればクラス・staticでなければプロトタイプ
- 第二引数：プロパティーキー・プロパティー名
- 第三引数：裏設定（PropertyDescriptor）

- (target, key, descriptor)

descriptor には：
- value（元メソッド）
- writable
- enumerable
- configurable
などが入る

## ③アクセサデコレータ
アクセサは get name() / set name(v) のようなものなので、メソッド名というよりアクセサ対象のプロパティ名

- 第一引数：スタティックであればクラス・staticでなければプロトタイプ
- 第二引数：プロパティーキー・プロパティー名
- 第三引数：裏設定（PropertyDescriptor）

```ts
get fullName()
ここなら "fullName" が第二引数
第三引数は descriptor でOK
```

## ④パラメータデコレータ
- 第一引数：スタティックであればクラス・staticでなければプロトタイプ
- 第二引数：プロパティーキー・メソッド名
- 第三引数：パラメータが何番目に来ているか

- (target, key, parameterIndex)

例：
```ts
save(@Req req, @Body body)
req = 0
body = 1
```
**補足** ：parameter decorator の第二引数

コンストラクタ引数に使う場合：`constructor(@Inject() repo: Repo)`

この場合、第2引数は undefined になる
（メソッド名が存在しないため）


## まとめ
| 種類        | 引数                                  |
| --------- | ----------------------------------- |
| Property  | target, propertyKey                 |
| Method    | target, propertyKey, descriptor     |
| Accessor  | target, propertyKey, descriptor     |
| Parameter | target, propertyKey, parameterIndex |
