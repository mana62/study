# シングルトン
- アプリ全体でインスタンスを**1つだけに強制**する設計パターン

① new を禁止
② 唯一のインスタンスを static に保存
③ getInstance() で返す

## 定型文
```ts
class Singleton {
  private static instance: Singleton;
  private constructor() {}
  static getInstance() {
    if (!this.instance) {
      this.instance = new Singleton();
    }
    return this.instance;
  }
}
```

| 役割 | なぜ必要？ |
|------|------------|
| **private constructor** | 外から `new` されると Singleton が崩壊するため |
| **private static instance** | “唯一のインスタンス” を保存する箱が必要 |
| **static getInstance()** | インスタンスを作る場所を 1 箇所に固定するため |

→ **この3つが揃うと Singleton が成立**

---

● private constructor
→ 勝手に new させないための鍵

● static instance
→ 唯一のインスタンスをしまっておく金庫

● getInstance()
→ 金庫から取り出す唯一の入口

この3つが揃って初めて Singleton になる
