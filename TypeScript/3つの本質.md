# TypeScript の3つの本質
＝ TypeScript には、実際には **3つの役割（側面）** がある

TypeScript は
**① 型によるドキュメント性**
**② 静的解析（Lint 的役割）**
**③ JavaScript へのコンパイル**
の**3つの側面**を持つ言語です。

## ① 型によるドキュメント性（Self-documenting）
TypeScript の型は：
- 何が入るのか
- 何を返すのか
- どう使うべきか
をコードそのものが説明してくれる

例：
```ts
function greet(name: string): string {
  return `Hello ${name}`;
}
```
→ これだけで「name は string」「返り値も string」とわかる

## ② 静的解析（Lint 的な役割）
TypeScript は型チェックを通して：
- 間違った型
- 存在しないプロパティ
- 間違った関数呼び出し
- null の可能性
などを **実行前**に検出できる

## ③ コンパイラ（JS への変換）
- TypeScript は JavaScript にコンパイルされる言語
- TypeScript → JavaScript に変換する
- これを コンパイル と呼ぶ
- tsc（TypeScript Compiler）が行う

## まとめ
TypeScript には次の3つの側面がある：
- ドキュメント性 → 型がコードの意味を説明してくれる
- 静的解析（Lint 的役割）→ 実行前にエラーを検出できる
- コンパイル（TS → JS）→ TypeScript Compiler（tsc）が JavaScript に変換する
