# スクリプトモジュール

JavaScript には 2つの動作モード がある
- スクリプト
- モジュール

## 違いと特徴
### ■ スクリプト（Script）
- 従来の JS の動き方
- グローバルスコープ
- this は window
- import/export は使えない
- HTML の <script> で読み込む昔ながらの書き方

### ■ モジュール（Module）
- ES6 以降の新しい仕組み
- ファイルごとにスコープが分離
- this は undefined
- import/export が使える
- <script type="module"> で読み込む

## どうやって Script / Module を識別している？
- ファイル内に import または export があるかどうか

  - ない → Script として扱う
  - ある → Module として扱う

- これは JavaScript も TypeScript も同じルール

## TypeScript でも同じ概念がある理由
- TypeScript は JavaScript を拡張した言語だから、JS の「スクリプト / モジュール」の概念をそのまま引き継いでいる

## ts.config設定の moduleDetection
### ■ moduleDetection: "auto"（デフォルト）
- import/export があれば Module
- なければ Script → 普通の挙動

### ■ moduleDetection: "force"
- **すべてのファイルを強制的に Module として扱う**
- ⚠️ ただし 型宣言ファイル（.d.ts）は除外

👉 つまり：import/export がなくても、そのファイルは Module として扱われる

## まとめ
- JS には Script と Module がある
- TS も同じルールを使う
- import/export があれば Module
- なければ Script
- tsconfig の moduleDetection: "force" を使うと全部 Module として扱う（.d.ts を除く）
