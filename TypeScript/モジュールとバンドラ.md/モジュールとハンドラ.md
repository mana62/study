# モジュールとハンドラ （ファイル分割）
- **モジュール** ＝ **再利用するために部品としてまとめたコード**
- **ハンドラ** ＝ **イベントが起きたときに実行される処理**

→ 基本はJSと全て同じ

## 歴史
### ES5時代（2009）
  - JavaScript標準にはモジュール機能なし

→ そのため主に下記３つのやり方で分割していた

#### CommonJS（Node.js）
```js
const fs = require("fs")
module.exports = {}
```

#### AMD（RequireJS）
```js
define(...)
```

#### scriptタグ分割
```js
<script src="a.js"></script>
<script src="b.js"></script>
```
### ES6（2015）で公式モジュール登場
```js
import
export
```
→ 現在はこっちが主流

## import の5つの書き方（よく使うもの）
### 1. 名前付き import
```js
import { Food } from "./foods.js";
```

#### 別名も可能（as）
```js
import { Food as FoodList } from "./foods.js";
```
- 意味：foods.js で export された Food を読み込む

### 2. まとめて全部 import（*）
```js
import * as Utils from "./utils.js";
```
使い方：
```js
Utils.add()
Utils.sub()
```

### 3. default export（default）
```js
export default class User {}
```
- 1ファイルに 1つだけ

### 4. default import（名前自由）
```js
import Hoge from "./user.js"
```
なぜ名前自由？
→ **default はそのファイルで1個しかないので、受け取る側が自由に名前を付けられる**

```js
import User from "./user.js"
import AAAAA from "./user.js"
```
どっちでもOK

### 5. 混在型
```js
import User, { age, name } from "./user.js"
```
- default を1つ
- 名前付き export を複数

## 名前付き export と default export どっちが良いのか？
- 結論：最近は名前付き export が好まれやすい

```js
// 名前付き export
export const add = () => {}
export const sub = () => {}

// 読み込む側
import { add, sub } from "./math.js"
```

#### メリット
- 何を export してるか明確
- IDE補完しやすい
- リファクタしやすい
- 名前ミス減る

```js
// default export
export default class User {}

// 読み込み
import User from "./user.js"
```
#### メリット
- メインの1個だけ出す時は楽

## export の3つの書き方
### 1. 宣言と同時
```js
export const name = "Taro";
export function hello(){}
```

### 2. 最後にまとめる
```js
const name = "Taro";
function hello(){}

export { name, hello }; // 最後に書く
```

### 3. default
```js
export default class User {}
```

## 実行は1回のみ
```js
import "./config.js"
import "./config.js"
```

- もし２回書いていても、config.js の中身は **最初の1回だけ実行される**
- 以後は **キャッシュされる**
- → これを **モジュールキャッシュ** と言う

## 補足： nouncheckOption（tsconfig.jsonの設定）

- **配列やオブジェクトの添字アクセスにundefined の可能性を追加して厳しくする設定**

```bash
{
  "compilerOptions": {
    "noUncheckedIndexedAccess": true
  }
}
```

## JSのモジュールとハンドラと違う部分
- 仕組み自体はほぼ同じ
- 違いは **「型があるかどうか」**
