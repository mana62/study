# extends による制約
- ジェネリクスに **「こういうプロパティは必ず持っててね」と制約**をかける方法
- 「TはXを継承する」ではなく「Tは最低でもこの形を持っていること」という制約
- 余分なプロパティがあってもOKで、あくまで最低限を保証する

## 例
```ts
function copy<T extends { name: string }>(value: T): T {
  return value;
}

copy({ name: "taro", age: 20 }); // OK
copy({ name: "taro" }); // OK
copy({ age: 20 }); // ❌ nameがない
```
→ 「T は name を持っている型じゃないとダメ」という制約をつけているだけ
→ 単に **T の条件** を書いているだけ

## ポイント
- extends で「Tは必ず name プロパティを持つ」と制約できる
- これで、nameがないオブジェクトを渡すとエラーになる


## まとめ
- extends は "T に条件をつける" ためのもの  
- → "この型だけ受け取っていいよ" と制限できる
