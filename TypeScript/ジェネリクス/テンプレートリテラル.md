# テンプレートリテラル型
- テンプレートリテラル型 = **文字列を「型レベル」で組み立てる仕組み**
- **リテラル型やユニオン型と組み合わせると 文字列のパターン を型として表現できる**

### 例
```ts
type name = 'taro';
type age = 30;
type info = `${name}は${age}歳です。`;
```

→ ① name と age は リテラル型
```ts
type name = 'taro'; // 値が 'taro' に固定された型
type age = 30;      // 値が 30 に固定された型
```

→ ② テンプレートリテラル型で文字列を組み立てる
```ts
type info = `${name}は${age}歳です。`;
```
**型レベルで文字列を合成**している

結果は
```ts
type info = "taroは30歳です。"
```
つまり info は **その文字列しか許さない型** になる

## ユニオン型と組み合わせると便利
```ts
type Method = 'GET' | 'POST';
type Path = '/users' | '/items';

type API = `${Method} ${Path}`;
```

API は：
```bash
"GET /users" | "GET /items" | "POST /users" | "POST /items"
```
→ API の文字列を完全に型で保証できる


## テンプレートリテラル型まとめ

| 項目 | 説明 | 何をするもの？ | どこで使う？ | 例 | 何が嬉しい？ |
|------|------|----------------|--------------|-----|--------------|
| 基本 | 文字列を型レベルで組み立てる仕組み | リテラル型を埋め込んだ文字列型を作る | ラベル生成・API パス・メッセージ型 | `${A}は${B}` | 文字列のパターンを型で保証できる |
| リテラル型との関係 | `'taro'` や `30` のような固定値型を使う | 文字列の一部を固定化できる | 固定メッセージ・定数名 | `'taroは30歳です。'` | 誤字や違う文字列を防げる |
| ユニオン型との併用 | `${A | B}` のように複数パターンを許可 | 文字列の組み合わせを型で表現 | ルーティング・イベント名 | `${'GET' | 'POST'} /users` | 組み合わせの網羅性を保証 |
| 実用例 | API のエンドポイント、ログメッセージ、CSS クラス名 | 文字列の構造を型で縛る | Next.js, Vue, React | `/users/${id}` | 文字列のミスをコンパイル時に検出 |
