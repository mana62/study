# keyof 演算子
- オブジェクトの **「キー名」を型として取り出す**

```ts
// 例
type K = keyof { name: string; age: number }
// → type K = "name" | "age"
```

## ポイント
- オブジェクトのキーを型として扱える
- ジェネリクスと組み合わせると、より柔軟な型が作れる

## 使い所
- obj[key] のkeyに「存在するキーしか入れられない」ことを保証するときに使う
- オブジェクトのキーだけ受け取る関数を作る時

## ⚠️ 注意
- オブジェクトのキー以外には使えない
- 配列のインデックスにも使える（0, 1, 2...）

## まとめ
- keyof は "オブジェクトのキーだけ" を取り出す演算子
- ジェネリクスと組み合わせると、より柔軟な型が作れる
