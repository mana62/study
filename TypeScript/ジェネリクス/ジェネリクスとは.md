# ジェネリクス
- **型を引数として受け取る仕組み**
- 普通の関数は「値」を受け取る
- ジェネリクスは 「型」も受け取れる関数

## 普通に型を書くのと何が違うの？
### 普通の関数（型を固定）
```ts
function copyString(value: string): string {
  return value;
}

copyString("hello"); // OK
copyString(123);   // ❌ エラー
```

### ジェネリクス（型を引数にする）
```ts
function copy<T>(value: T): T {
  return value;
}
// T に何でも入れられる（string, number, object…）

copy("hello"); // string
copy(123);   // number
copy(true);  // boolean

// 呼び出す時は型を書かなくても推論してくれる
```

つまり：
- ジェネリクスは **「型を後から決められる関数」**
- → 再利用性が爆上がりする

## 使える場所
- 関数
- クラス
- 型エイリアス
- インターフェース
全部で使える

```ts
const fn = <T>(v: T) => v; // 関数
class Box<T> { constructor(public value: T) {} } // クラス
type ApiResponse<T> = { data: T } // 型エイリアス
```

## メリット
- 型を「引数」として受け取る（再利用できる）
- 柔軟性が高い
- 呼び出す時は型を明示しなくても推論してくれる
