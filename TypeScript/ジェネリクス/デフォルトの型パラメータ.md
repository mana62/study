# デフォルトの型パラメータ
- 関数の「デフォルト引数」と同じイメージで、**型にもデフォルト値を設定できる**

```ts
// T のデフォルトを { message: string } に設定
interface ResponseData<T = { message: string }> {
  data: T;
  status: number;
}

// 型引数を省略 → T は { message: string } になる
let r1: ResponseData = {
  data: { message: "ok" },
  status: 200,
};

// 型引数を指定 → その型が使われる
interface User {
  id: number;
  name: string;
}
let r2: ResponseData<User> = {
  data: { id: 1, name: "Taro" },
  status: 200,
};

```
❗️ よく使われる型は「デフォルト」にしておくと、毎回書かなくて済んで便利

## まとめ
- 関数のデフォルト引数と同じ感覚です。型を省略したときに使われる型を設定できる
