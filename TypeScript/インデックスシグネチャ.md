# インデックスシグネチャ
- **オブジェクトの型 に対して使う** TS の機能
- **キーが増えてもOKなオブジェクトの型**

例：
```ts
interface Designer {
  name: string;
  [key: string]: string; // このオブジェクトはstring のキーを持ち、値も string である
}

const designer = {
  name: "taro",
  hobby: "cooking", // [key: string]: string;この型に沿っていれば何個でも作れる
  skill: "photoshop"
};
```

## 使い方
```ts
// 定型文
[key名: キーの型]: 値の型

// このように書くと、[key: string]: string; の型に沿っていれば何個でも作れる
[key: string]: string;
```

## 使いどころ
- キーが動的に増える場合
- キー名が決まっていない
- キーが決まってないオブジェクト
- APIレスポンス
- 辞書みたいなデータ

## 似た意味を持つもの
- **Record**
```ts
type Designer = Record<string, string>;
```
