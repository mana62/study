# static
- **new しなくても使える クラス専用のメソッド・プロパティ**
- インスタンス（＝new したオブジェクト）には属さない
- クラスそのものにくっついている
- だから **this は使えない**（インスタンスが存在しないため）

例：
```ts
class Person {
  // staticは、メソッド名の前に付ける
  static isAdult(age: number) {
    return age >= 20;
  }
}
```

```ts
// 使い方
Person.isAdult(25); // true（ドットでアクセス）
```
- **new Person() しなくても呼べる**
- Person という設計図に直接アクセスしているイメージ

```bash
┌──────────────┐
│   Person（設計図） │  ← static はここにくっつく
│  ───────────── │
│  static isAdult │
└──────────────┘

┌──────────────┐
│ new Person()   │  ← インスタンスには static は存在しない
└──────────────┘
```

## static の中で this が使えない理由
- **this は インスタンスを指す**
- **でも static メソッドは インスタンスを作らずに呼ばれる**（newしないからインスタンスが作られない = thisは何も指させないから使えない）

```ts
class Person {
  static isAdult() {
    console.log(this); // ❌ これは Person クラスそのものを指す、インスタンスを指してない
  }
}
```
- static メソッドの中の this は インスタンスではなく **クラス自身 を指す**
- つまり **this === Person** になる
- static 内の this は「インスタンス」ではなく「クラス」を指す
- だから インスタンスのプロパティにはアクセスできない

## JSとの違い
staticはJSにもTSにも存在するが
- 型があるかどうか
- コンパイル時チェックがあるかどうか
👉 つまり、構文は同じでも、TS のほうが安全で強力に使える

## this の違い
| 場所 | this が指すもの |
|------|----------------|
| 通常メソッド | インスタンス |
| static メソッド | クラスそのもの |
| アロー関数（static 内） | 外側の this（＝クラス） |


## まとめ
- static は「インスタンスじゃなくて **クラス自身が持つ機能**」
- だから **new しないで使えるし、this（インスタンス）は存在しない**
- 通常メソッドの this は インスタンス

| 概念 | 意味 |
|------|------|
| static | new しなくても使える “クラス専用” のメソッド/プロパティ |
| 使い方 | Person.isAdult() のようにクラス名から呼ぶ |
| this が使えない理由 | インスタンスが存在しないため（static 内の this はクラスを指す） |
| 例 | Math.random() と同じ仕組み（インスタンス不要） |
