# オプショナルチェーニング （?.）
- プロパティやメソッドに使える
- 途中でnullでもエラーにせず止まる

例：
```ts
console.log(user?.profile?.name);
```

## 定型文
```ts
obj?.プロパティ
obj?.メソッド()
```

## 使い道
- APIデータ
- ネストが深いオブジェクト
- nullやundefindになる可能性のある場所

## 同じ意味の別の方法
### ① if文
```ts
if (user && user.profile) {
  console.log(user.profile.name);
}
```

### ② !（危険）
```ts
user!.profile!.name
```
