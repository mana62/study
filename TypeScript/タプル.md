# タプルの時の型

## タプルとは
**順番と型が決まってる配列**

例：
```ts
let user: [number, string] = [1, "taro"];
```
1番目 → number
2番目 → string

## 普通の配列との違い
```ts
number[]      // なんでもOK
[number,string] // 順番固定（タプル）
```

## タプル + rest
例：
```ts
type Data = [number, string, ...number[]];
```
意味：
1個目：number
2個目：string
それ以降：number何個でも

### ⚠️ 注意
`...number[]` は最後に配置

## タプルのオプショナル（?）
例：
```ts
type Data = [number, string, boolean?];
```
意味：
boolean はあってもなくてもOK

### ⚠️ 注意
```ts
[number, string?, ...number[]]
```
**optional（?）の後にrestは基本NGになる**ケースあり
→ 順番に注意！

## ラベル付きタプル
**タプルに名前つけるだけ**（意味は変わらない）

例：
```ts
type User = [id: number, name: string, hasPet?: boolean];
```

### メリット
読みやすいだけ
```ts
// どっちが分かりやすい？
[number, string, boolean]
[id: number, name: string, hasPet: boolean]
```

## ⚠️ 注意
型には影響なし（ただのラベル）

## readonly（配列・タプル）
変更できない配列

例：
```ts
const arr: readonly number[] = [1,2,3];

arr[0] = 10; // ❌ エラー
```

### 関数で使う
```ts
function add(...arg: readonly number[]) {
  // argは変更不可
}
```

| 書き方               | 意味     |
| ----------------- | ------ |
| readonly number[] | 読み取り専用 |
| number[]          | 書き換えOK |

## as const
**値を「完全に固定」する**

例：
```ts
// 通常
let milk = "milk";
// 型はstring

// as const
let milk = "milk" as const;
// 型は"milk" ← 完全固定（リテラル型）
```

| 書き方             | 型          |
| --------------- | ---------- |
| "milk"          | string     |
| "milk" as const | "milk"（固定） |

### 配列の場合
```ts
const arr = [10, 20] as const;
```

型
```ts
readonly [10, 20]
```

### オブジェクト
```ts
const person = {
  name: "taro",
  age: 38
} as const;
```
型
```ts
{
  readonly name: "taro";
  readonly age: 38;
}
```

## constではダメな理由
```ts
const x = "milk";

// 型は"milk" ✅（これはOK）
```

```ts
const obj = {
  name: "taro"
};

{ name: string } ❌（広がる）
```
as const を使うと：

```ts
const obj = {
  name: "taro"
} as const;

{ readonly name: "taro" }
```
as const は
- 型を固定
- readonlyにする
- リテラル化する

- const → 変数の再代入だけ禁止。中身の型はゆるい
- as const → 中身まで全部固定。型が厳密になる


| 機能         | 一言         |
| ---------- | ---------- |
| rest       | 引数まとめる     |
| タプル        | 型と順番固定     |
| タプル + rest | 後ろだけ自由     |
| ?          | あってもなくてもOK |
| ラベル付きタプル   | 名前つけるだけ    |
| readonly   | 変更禁止       |
| as const   | 完全固定（超重要）  |
