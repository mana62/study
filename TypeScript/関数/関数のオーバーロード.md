# 関数のオーバーロード
- 入力（引数）と出力（戻り値）をセットで対応させたい時に使う
- **引数によって戻り値の型を変える**こと
- **呼び出す側から見て、戻り値の型が特定できないとき**に使う

例：
```ts
function fn(x: string | number): string | number {
  return x;
}
// 上記だと戻り値もどっちかよくわからない
// なので↓



function toUpperCase(x: string): string;
function toUpperCase(x: number): number;
// 上記は下記の引数に沿って、一個ずつ型を定義（下記の引数以外の型を宣言すればエラー）
// 下記が本当の関数
function toUpperCase(x: string | number) {
  if (typeof x === "string") {
    return x.toUpperCase();
  }
  return x;
}
```

## 定型文
```ts
// 引数が多ければその分だけ書ける
function fn(引数: 型): 戻り値;
function fn(引数: 型): 戻り値;

// 普通に関数を定義
function fn(引数: union型) {
  実装
}
```

## 使うタイミング
- 引数によって返す型が変わるとき
- ライブラリっぽい関数

## ⚠️ 注意
- ユニオン型のときだけ使うわけじゃない → ユニオン型だと型が曖昧になるときに使う
- **アロー関数やオブジェクトのメソッドではオーバーロードは使えない**
- 必ず、funxtionの関数宣言をする必要がある
