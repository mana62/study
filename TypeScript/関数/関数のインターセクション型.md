# 関数のインターセクション型（関数 & 関数）

## 「インターセクション型」とは？
**A & B** = 「AでありかつBでもある」型

## 関数同士を&でつなぐと？
```ts
type Func1 = (a: number, b: string) => number
type Func2 = (a: number) => number

type IntersectionFunc = Func1 & Func2 //.  Func1 かつ Func2

// 呼び出し
fn(42)      // ✅ numberを渡す → numberが返ってくる
fn("hello") // ✅ stringを渡す → stringが返ってくる
```
**どちらも使える！ これがオーバーロードの意味**

結果：**オーバーロード（「渡すものによって動きが変わる関数」）された関数と同じ形になる**

```ts
// つまりこれと同じ意味
function overloaded(a: number, b: string): number
function overloaded(a: number): number
```

## オーバーロードとは
オーバーロードとは **「同じ関数名で、引数のパターンが違う版を複数用意すること」**

```ts
// 引数がnumberのとき→numberを返す
function hello(a: number): number

// 引数がstringのとき→stringを返す
function hello(a: string): string
```
**「渡すものによって動きが変わる関数」**のこと

## ⚠️ 順番に注意！
- **Func1 & Func2 と Func2 & Func1 ではオーバーロードの順番が変わる**
- TypeScriptはオーバーロードを上から順にマッチングするので、順番が結果に影響する
