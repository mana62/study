# 型を自動生成する仕組み （typeof + as const ）
- **typeof + as const を使うと そのリテラル型（値が固定された型＝リテラル型）が自動生成される**

### 例
```ts
// 実際のデータ (値)
const profile = {
name: "taro",
age: 20,
} as const

↓

// typeof
type ProfileType = typeof profile;

↓

// 生成される型
type ProfileType = {
name: "taro",
age: 20,
}
```

## ポイント
- 型を手書きしなくても、既存のオブジェクトから自動で型定義を作れる
- データと型が常に一致する

## ⚠️ 注意
- as const がないと？ → `name: string, age: number` という広い型になってしまう
- as const をつけると → `name: "taro", age: 20` という厳密なリテラル型になる

## 使いどころ
- オブジェクトのキーに使うと、外から絶対に上書きできないプロパティが作れる
- ライブラリのプライベートIDなど「衝突してはいけない値」に使う

## メリット
- 値が真実 → 型が自動生成
- 値を変えれば型も自動で変わる
- ズレない
- バグらない
- 実務で最強
- 型と値を２回書く必要がない


## まとめ
- typeof + as const は "値を唯一の真実として型を自動生成する仕組み"
- 最初からリテラル型を書くのは、値と型を二重管理する古い方法
