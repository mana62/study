# インターセクション型 （A & B） （A かつ B）
- 2つ以上の型を **合体** させて、全部入りの型を作る仕組み

## 例
```ts
Engineer = { name, role }
Blogger = { name, follower }

//エンジニア かつ ブロガー
const x = Engineer & Blogger;

```
- xは、**{ name, role, follower } を全部持つ型**になる
- followerやroleなど、どれか一つでもなかったらエラー

## いつ使うのか？
- ** 2つの役割を同時に持つ** 人や物 を表したいとき
    - エンジニアでもありブロガーでもある人
    - ログイン情報 + プロフィール情報を合体した型
    - API のレスポンスを複数の型から合成したいとき など

## 存在する意味
- **型を再利用しながら、必要なものを全部まとめたい** というニーズに応えるため

もし毎回こう書くのは面倒：
```ts
type EngineerBlogger = {
  name: string;
  role: string;
  follower: number;
}
```

& を使えば：
```ts
type EngineerBlogger = Engineer & Blogger;
```
→ **DRY（同じことを繰り返さない） を実現できる**

## ポイント
- & は **全部必要** の意味
- プロパティが重複したら、両方の型が一致している必要がある
- ユニオン（|）と真逆の性質

## ⚠️ 注意
- && → 実行時の「かつ」（条件分岐など）（JSなど）
- & → 型レベルの「かつ」（型の合成）
