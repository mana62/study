# JSの型とTSの型の役割と違い
- TypeScript : **静的型付け**
- JavaScript : **動的型付け**

- 静的型付け → 型が「先に」決まる
- 動的型付け → 型が「後で」決まる（実行してから）

| 観点      | JavaScriptの型 | TypeScriptの型    |
| ------- | ------------ | --------------- |
| いつ使われる？ | 実行時          | コンパイル時          |
| 誰が使う？   | JSエンジン       | TypeScriptコンパイラ |
| 消える？    | 消えない         | 実行時には消える        |
| 役割      | 実行のため        | バグ防止・型チェック      |


| 項目 | TypeScript | JavaScript |
|------|------------|------------|
| 型推論 | ある（しかも強力） | ない |
| 推論された型 | 変更不可で安全性を保証 | 変更可能で安全性なし |
| 型注釈 | 必要なところだけ書く | そもそも存在しない |
| コードの安全性 | 高い | 低い |

⚫︎TypeScriptは型がめちゃくちゃ多い
- union型（string | number）
- literal型（"ok"みたいな固定値）
- tuple型
- interface
- generics
👉 これらはJavaScriptには存在しない
