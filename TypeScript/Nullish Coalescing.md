# Nullish Coalescing （??）
- 右側がnullかundefinedなら代わりを使う

例：
```ts
const name = user ?? "ゲスト";
```

## 定型文
```ts
値 ?? デフォルト値
```

## 使い道
- デフォルト値を入れたいとき

## 似てる別の方法
### ① OR (||)
```ts
const name = user || "ゲスト";
```

## OR との違い
```ts
"" || "ゲスト"  → "ゲスト"（空文字もNG扱い）
"" ?? "ゲスト" → ""（空文字OK）
```
**→ ?? の方が安全**
