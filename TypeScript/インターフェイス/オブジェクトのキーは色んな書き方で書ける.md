# オブジェクトのキーは色んな書き方でかける
- オブジェクトのキーは [] を使うと変数で決められる

## 普通の書き方
```ts
const data = {
  name: "太郎"
};
```
これが基本

## 変数をキーにする
```ts
const key = "name";

const data = {
  [key]: "太郎"
};
```
意味：**keyの中身がキーになる**

結果：
```ts
data.name // "太郎"
```

## TypeScriptでも同じことできる
```ts
const key = "name";

type Data = {
  [key]: string;
};
```
意味：key = "name" だから name: string と同じ

## なんでこんな書き方するのか？
結論：**キーを「動的に決めたい」時**

```ts
const userId = "user123";

const data = {
  [userId]: "データ"
};
```

## ⚠️ ダメな例
```ts
type Data = {
  [key: string]: string;
};
```
意味：「どんなキーでもOKなオブジェクト」
変数をキーにしていない、直書き

## 「オブジェクトのキーとして最終的に使える型」がこの3つだけ

- string（文字）
- number（数字）
- symbol（ちょい特殊）

## アクセス方法2つ
```ts
data.name        // 普通
data["name"]     // 同じ意味

data["user-id"] // ハイフンあるとドット使えない時はこう
```

##　まとめ
- **オブジェクトのキーは [] を使うと変数で決められる**
