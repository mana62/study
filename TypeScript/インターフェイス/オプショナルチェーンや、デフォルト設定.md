# オプショナルプロパティ、オプションパラメータ　、デフォルト引数
- オプショナルプロパティ：?をつけることで値があってもなくてもOKなようにする
- オプションパラメータ：?をつけることで値があってもなくてもOKなようにする
- デフォルト引数：デフォルトの値を指定しておくこと

## 「?」の意味
```ts
name?: string;
```
意味：nameの値が、あってもなくてもいい

例：
```ts
type User = {
  name: string;
  nickname?: string;
};
```
OK： `{ name: "太郎" }`
OK： `{ name: "太郎", nickname: "タロちゃん" }`
❌NG： `{ name: "太郎", nickname: "タロちゃん" }`（nameには?がないから必須）

## パラメータにも使える　（オプションパラメータ）
```ts
function greet(message?: string) {
}
```
意味：引数なくてもOK

呼び出し：
```ts
greet();          // OK
greet("hello");   // OK
```

## ⚠️ 注意：undefinedになる
```ts
function greet(message?: string) {
  console.log(message);
}
```

messageの正体： `string | undefined`

なので下記のようにする：
```ts
if (message) {
  message.toUpperCase();
}
```
- message は「string かもしれないし、undefined かもしれない」から
- だから **undefined のまま toUpperCase() を呼ぶとエラーになる**

## 「?」と「string | undefined」は違う
```ts
name: string | undefined;
```
意味：「nameは必須、でも中身がundefinedでもOK」
つまり、{ } ❌ ダメ（nameが無い）

```ts
name?: string;
```
意味：「name自体なくてもOK」

## デフォルト引数とは
```ts
function greet(message = "hello") {
}
```
- 引数にあらかじめデフォルトの値を入れること

## 違い
| 書き方                 | 意味            |
| ------------------- | ------------- |
| `message?: string`  | 無いと undefined |
| `message = "hello"` | 無いと "hello"   |

## クラスでも使える
```ts
class User {
  name?: string;
}
```
- 初期化しなくてもOK

## ルール
```ts
function test(a: number, b?: number) {}
```
- OK

```ts
function test(a?: number, b: number) {}
```
- ❌NG

👉 **?は最後に書く**（最初に書くのはダメ！）
